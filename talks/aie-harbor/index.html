01 · Overview

What is Harbor?

Harbor runs AI agents against real tasks in sandboxed environments, then scores what they leave behind.

Taskan instruction, an image, a test
Agent worksin a fresh sandbox
Verifier checkswhat the agent left behind
Reward0 to 1, plus a trajectory

Run it for every agent you want to compare. Same task, same sandbox, same verifier.
