# Menus

A menu is built from parts, and each entry here covers the part that owns
an option. A `MenuTrigger` pairs a trigger with a `Menu Container`, the
popover surface that sets the menu's size and where it opens. The
container holds a `Menu`, the list with its selection mode and empty
state, made of `Menu Item`s, each with its own content and states. A
`Grid List` takes the list's place when rows carry their own controls.
`Composition` adds what else a container can hold: a header, a footer,
sections and submenus. `Menu Button` is a prebuilt trigger and menu.
