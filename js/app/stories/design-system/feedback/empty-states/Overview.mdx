# Empty states

What a surface shows when it has nothing to show yet. `EmptyState` lays out
the title, description, and actions; its optional `graphic` is an
`EmptyStateGraphic`, which pins one icon and size per region or topic so a
given surface looks the same everywhere. In Context shows both at the places
Phoenix renders them.
