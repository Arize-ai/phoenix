# Storybook health

Where the story set stands. Regenerated by `pnpm lint:stories`, which already
parses every story file — so this page is computed from the tree rather than
maintained by hand and cannot quietly fall out of date.

## Documentation coverage

Sections with an MDX page: {health.sectionsWithDocsPage.length}

<ul>
  {health.sectionsWithDocsPage.map((section) => (
    <li key={section}>
      <code>{section}</code>
    </li>
  ))}
</ul>

Documentation coverage is computed here rather than tagged. "Has an adjacent
MDX page" is derivable from the tree, and a tag that restates something
derivable only creates a second version of the truth that can disagree with the
first.
