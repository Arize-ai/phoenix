Arize Phoenix হলো Arize-এর ওপেন-সোর্স AI observability প্ল্যাটফর্ম, যা পরীক্ষা-নিরীক্ষা (experimentation), মূল্যায়ন (evaluation) এবং সমস্যা সমাধানের জন্য ডিজাইন করা হয়েছে। ম্যানেজড প্রোডাকশন ওয়ার্কফ্লোর জন্য Arize [Arize AX](https://arize.com/products/ax/)-ও প্রদান করে। Phoenix যা প্রদান করে:

- [**_ট্রেসিং_**](https://arize.com/docs/phoenix/tracing/llm-traces) - OpenTelemetry-ভিত্তিক instrumentation ব্যবহার করে আপনার LLM অ্যাপ্লিকেশনের রানটাইম ট্রেস করুন।
- [**_মূল্যায়ন_**](https://arize.com/docs/phoenix/evaluation/llm-evals) - response ও retrieval evals ব্যবহার করে আপনার অ্যাপ্লিকেশনের পারফরম্যান্স বেঞ্চমার্ক করতে LLM কাজে লাগান।
- [**_ডেটাসেট_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets) - পরীক্ষা-নিরীক্ষা, মূল্যায়ন এবং fine-tuning-এর জন্য উদাহরণের ভার্সন-যুক্ত ডেটাসেট তৈরি করুন।
- [**_এক্সপেরিমেন্ট_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets#experiments) - prompt, LLM এবং retrieval-এ পরিবর্তনগুলো ট্র্যাক ও মূল্যায়ন করুন।
- [**_Playground_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts)- prompt অপ্টিমাইজ করুন, মডেল তুলনা করুন, প্যারামিটার সামঞ্জস্য করুন এবং ট্রেস করা LLM কল পুনরায় চালান।
- [**_প্রম্পট ব্যবস্থাপনা_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts/prompt-management)- ভার্সন কন্ট্রোল, ট্যাগিং এবং পরীক্ষা-নিরীক্ষার মাধ্যমে prompt-এর পরিবর্তনগুলো পদ্ধতিগতভাবে পরিচালনা ও পরীক্ষা করুন।
- [**_PXI (Phoenix Intelligence)_**](https://arize.com/docs/phoenix/pxi) - Phoenix-এ বিল্ট-ইন একটি AI ইঞ্জিনিয়ারিং এজেন্ট, যা trace ডিবাগ করা, prompt নিয়ে বারবার উন্নতি করা এবং প্রোডাক্টে নেভিগেট করার জন্য তৈরি।
- [**_Remote MCP Server_**](https://arize.com/docs/phoenix/integrations/remote-mcp) - Claude Code, Cursor এবং অন্যান্য MCP ক্লায়েন্টকে সরাসরি আপনার Phoenix ইনস্ট্যান্সের `/mcp` endpoint-এ সংযুক্ত করে trace, dataset, experiment এবং আরও অনেক কিছু query করুন।

Phoenix কোনো নির্দিষ্ট ভেন্ডর বা ভাষার ওপর নির্ভরশীল নয় এবং জনপ্রিয় ফ্রেমওয়ার্ক ([OpenAI Agents SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai-agents-sdk), [Claude Agent SDK](https://arize.com/docs/phoenix/integrations/python/claude-agent-sdk), [LangGraph](https://arize.com/docs/phoenix/tracing/integrations-tracing/langchain), [Vercel AI SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/vercel-ai-sdk), [Mastra](https://arize.com/docs/phoenix/integrations/typescript/mastra), [CrewAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/crewai), [LlamaIndex](https://arize.com/docs/phoenix/tracing/integrations-tracing/llamaindex), [DSPy](https://arize.com/docs/phoenix/tracing/integrations-tracing/dspy)) ও LLM প্রোভাইডারের ([OpenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai), [Anthropic](https://arize.com/docs/phoenix/tracing/integrations-tracing/anthropic), [Google GenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/google-genai), [Google ADK](https://arize.com/docs/phoenix/integrations/llm-providers/google-gen-ai/google-adk-tracing), [AWS Bedrock](https://arize.com/docs/phoenix/tracing/integrations-tracing/bedrock), [OpenRouter](https://arize.com/docs/phoenix/integrations/python/openrouter), [LiteLLM](https://arize.com/docs/phoenix/tracing/integrations-tracing/litellm) এবং আরও অনেক) জন্য সরাসরি সমর্থন দেয়। auto-instrumentation সম্পর্কে বিস্তারিত জানতে [OpenInference](https://github.com/Arize-ai/openinference) প্রজেক্টটি দেখুন।

Phoenix প্রায় যেকোনো জায়গায় চলে, যেমন আপনার লোকাল মেশিন, কন্টেইনারাইজড ডিপ্লয়মেন্ট বা ক্লাউড। প্রতিটি বিকল্পের বিস্তারিত নির্দেশনার জন্য [Environments](https://arize.com/docs/phoenix/environments) দেখুন, অথবা সরাসরি [Tracing Quickstart](https://arize.com/docs/phoenix/get-started/get-started-tracing)-এ চলে যান।

> [!NOTE]
> Phoenix ওপেন-সোর্স এবং self-hosted। ম্যানেজড প্ল্যাটফর্মের জন্য Arize [Arize AX](https://arize.com/products/ax/) প্রদান করে — একই OpenTelemetry/OpenInference instrumentation উভয়ের সাথেই কাজ করে। [সম্পূর্ণ তুলনা](https://arize.com/docs/phoenix/resources/frequently-asked-questions/what-is-the-difference-between-phoenix-and-arize) দেখুন।

## লোকালি চালান

`pip` বা `conda` ব্যবহার করে Phoenix ইনস্টল করুন এবং একটি সম্পূর্ণ কার্যকর Phoenix পান। সব ইনস্টলেশন ও হোস্টিং বিকল্পের জন্য [ইনস্টল গাইড](https://arize.com/docs/phoenix) দেখুন।

```shell
pip install arize-phoenix
phoenix serve
```

অথবা কোনো ইনস্টল ছাড়াই [`uvx`](https://docs.astral.sh/uv/) দিয়ে চালান:

```shell
uvx arize-phoenix serve
```

## আপনার অ্যাপ্লিকেশন ট্রেস করুন

trace পাঠানোর সবচেয়ে দ্রুত উপায় হলো আপনার [কোডিং এজেন্টকে](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) (Claude Code, Codex, Cursor এবং অন্যান্য) দিয়ে আপনার অ্যাপ instrument করানো। আপনার প্রজেক্ট ডিরেক্টরি থেকে চালান:

```shell
npx @arizeai/phoenix-cli setup
# অথবা, Phoenix ইনস্টল থাকলে: px setup
```

Setup আপনার ফ্রেমওয়ার্ক ও LLM প্রোভাইডার শনাক্ত করে, সঠিক [OpenInference](https://github.com/Arize-ai/openinference) instrumentation ইনস্টল করে এবং trace export কনফিগার করে। কোডের মাধ্যমে সেট আপ করতে চান? [ট্রেসিং ডকুমেন্টেশন](https://arize.com/docs/phoenix/tracing/llm-traces) দেখুন।

## মানুষ ও কোডিং এজেন্টদের জন্য

Phoenix এমনভাবে তৈরি যাতে মানুষ ও AI কোডিং এজেন্ট উভয়েই এটি সমানভাবে চালাতে পারে। তিনটি মাধ্যম এজেন্টদের (Claude Code, Codex, Cursor এবং অন্যান্য) আপনার trace, dataset ও experiment নিয়ে কাজ করতে দেয়:

- **[CLI](https://arize.com/docs/phoenix/sdk-api-reference/typescript/arizeai-phoenix-cli)** — `npx @arizeai/phoenix-cli` trace, dataset ও experiment সংগ্রহ করে এবং আপনার অ্যাপ instrument করে (`setup`), যাতে একটি এজেন্ট টার্মিনাল থেকেই প্রসঙ্গ সংগ্রহ করে সে অনুযায়ী কাজ করতে পারে।
- **[Skills](https://docs.anthropic.com/en/docs/claude-code/skills)** — [`.agents/skills/`](.agents/skills/) এমন ওয়ার্কফ্লো প্যাকেজ করে যা এজেন্টদের Phoenix দিয়ে ডিবাগ, মূল্যায়ন ও ট্রেস করতে শেখায়।
- **[Remote MCP Server](https://arize.com/docs/phoenix/integrations/remote-mcp)** — যেকোনো MCP ক্লায়েন্টকে আপনার ইনস্ট্যান্সের `/mcp` endpoint-এ সংযুক্ত করে সরাসরি Phoenix query করুন।

সেটআপ ও ব্যবহারের জন্য [কোডিং এজেন্ট ডকুমেন্টেশন](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) দেখুন।

| Skill | বিবরণ |

## নিরাপত্তা ও গোপনীয়তা

আমরা ডেটার নিরাপত্তা ও গোপনীয়তাকে অত্যন্ত গুরুত্ব দিই। আরও বিস্তারিত জানতে আমাদের [নিরাপত্তা ও গোপনীয়তা ডকুমেন্টেশন](https://arize.com/docs/phoenix/self-hosting/security/privacy) দেখুন।

### টেলিমেট্রি

ডিফল্টভাবে, Phoenix কীভাবে ব্যবহৃত হয় তা বুঝতে এবং প্রোডাক্ট উন্নত করতে Phoenix মৌলিক ওয়েব অ্যানালিটিক্স (যেমন পেজ ভিউ, UI ইন্টারঅ্যাকশন) সংগ্রহ করে। **আপনার কোনো trace ডেটা, মূল্যায়নের ফলাফল বা কোনো সংবেদনশীল তথ্য কখনোই সংগ্রহ করা হয় না।**

এই environment variable সেট করে আপনি টেলিমেট্রি থেকে অপ্ট-আউট করতে পারেন: `PHOENIX_TELEMETRY_ENABLED=false`
