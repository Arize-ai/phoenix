Arize Phoenix، Arize کا اوپن سورس AI observability پلیٹ فارم ہے جو تجربات، جانچ (evaluation) اور مسائل کے حل کے لیے بنایا گیا ہے۔ پروڈکشن کے منظم (managed) ورک فلوز کے لیے Arize [Arize AX](https://arize.com/products/ax/) بھی پیش کرتا ہے۔ Phoenix درج ذیل سہولیات فراہم کرتا ہے:

- [**_ٹریسنگ (Tracing)_**](https://arize.com/docs/phoenix/tracing/llm-traces) - OpenTelemetry پر مبنی instrumentation کے ذریعے اپنی LLM ایپلیکیشن کے رن ٹائم کو ٹریس کریں۔
- [**_جانچ (Evaluation)_**](https://arize.com/docs/phoenix/evaluation/llm-evals) - جوابات اور retrieval کے evals استعمال کرتے ہوئے LLMs کی مدد سے اپنی ایپلیکیشن کی کارکردگی کا معیار جانچیں۔
- [**_ڈیٹا سیٹس (Datasets)_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets) - تجربات، جانچ اور fine-tuning کے لیے مثالوں کے ورژن شدہ ڈیٹا سیٹس بنائیں۔
- [**_تجربات (Experiments)_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets#experiments) - prompts، LLMs اور retrieval میں تبدیلیوں کو ٹریک کریں اور ان کی جانچ کریں۔
- [**_Playground_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts)- prompts کو بہتر بنائیں، ماڈلز کا موازنہ کریں، پیرامیٹرز کو ایڈجسٹ کریں، اور ٹریس شدہ LLM کالز کو دوبارہ چلائیں۔
- [**_Prompt مینجمنٹ_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts/prompt-management)- ورژن کنٹرول، ٹیگنگ اور تجربات کے ذریعے prompt میں تبدیلیوں کو منظم طریقے سے مینیج اور ٹیسٹ کریں۔
- [**_PXI (Phoenix Intelligence)_**](https://arize.com/docs/phoenix/pxi) - Phoenix میں شامل ایک AI انجینئرنگ ایجنٹ جو traces کی ڈیبگنگ، prompts پر بار بار بہتری، اور پروڈکٹ میں نیویگیشن کے لیے ہے۔
- [**_ریموٹ MCP سرور_**](https://arize.com/docs/phoenix/integrations/remote-mcp) - Claude Code، Cursor اور دیگر MCP کلائنٹس کو براہ راست اپنے Phoenix انسٹینس کے `/mcp` اینڈ پوائنٹ سے جوڑیں تاکہ traces، ڈیٹا سیٹس، تجربات اور مزید چیزوں کے بارے میں کوئری کر سکیں۔

Phoenix کسی مخصوص وینڈر یا زبان کا پابند نہیں ہے اور مقبول فریم ورکس ([OpenAI Agents SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai-agents-sdk)، [Claude Agent SDK](https://arize.com/docs/phoenix/integrations/python/claude-agent-sdk)، [LangGraph](https://arize.com/docs/phoenix/tracing/integrations-tracing/langchain)، [Vercel AI SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/vercel-ai-sdk)، [Mastra](https://arize.com/docs/phoenix/integrations/typescript/mastra)، [CrewAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/crewai)، [LlamaIndex](https://arize.com/docs/phoenix/tracing/integrations-tracing/llamaindex)، [DSPy](https://arize.com/docs/phoenix/tracing/integrations-tracing/dspy)) اور LLM فراہم کنندگان ([OpenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai)، [Anthropic](https://arize.com/docs/phoenix/tracing/integrations-tracing/anthropic)، [Google GenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/google-genai)، [Google ADK](https://arize.com/docs/phoenix/integrations/llm-providers/google-gen-ai/google-adk-tracing)، [AWS Bedrock](https://arize.com/docs/phoenix/tracing/integrations-tracing/bedrock)، [OpenRouter](https://arize.com/docs/phoenix/integrations/python/openrouter)، [LiteLLM](https://arize.com/docs/phoenix/tracing/integrations-tracing/litellm)، اور مزید) کے لیے فوری سپورٹ فراہم کرتا ہے۔ خودکار instrumentation کی تفصیلات کے لیے [OpenInference](https://github.com/Arize-ai/openinference) پروجیکٹ دیکھیں۔

Phoenix تقریباً ہر جگہ چلتا ہے، بشمول آپ کی مقامی مشین، کنٹینر پر مبنی ڈیپلائمنٹ، یا کلاؤڈ۔ ہر آپشن کی تفصیلی وضاحت کے لیے [ماحول (Environments)](https://arize.com/docs/phoenix/environments) دیکھیں، یا براہ راست [ٹریسنگ کوئیک اسٹارٹ](https://arize.com/docs/phoenix/get-started/get-started-tracing) پر جائیں۔

> [!NOTE]
> Phoenix اوپن سورس اور سیلف ہوسٹڈ ہے۔ منظم پلیٹ فارم کے لیے Arize [Arize AX](https://arize.com/products/ax/) پیش کرتا ہے — ایک ہی OpenTelemetry/OpenInference instrumentation دونوں کے ساتھ کام کرتی ہے۔ [مکمل موازنہ](https://arize.com/docs/phoenix/resources/frequently-asked-questions/what-is-the-difference-between-phoenix-and-arize) دیکھیں۔

## مقامی طور پر چلائیں

Phoenix کو `pip` یا `conda` کے ذریعے انسٹال کریں اور مکمل طور پر فعال Phoenix حاصل کریں۔ انسٹالیشن اور ہوسٹنگ کے تمام آپشنز کے لیے [انسٹالیشن گائیڈ](https://arize.com/docs/phoenix) دیکھیں۔

```shell
pip install arize-phoenix
phoenix serve
```

یا [`uvx`](https://docs.astral.sh/uv/) کے ذریعے بغیر انسٹالیشن کے چلائیں:

```shell
uvx arize-phoenix serve
```

## اپنی ایپلیکیشن کو ٹریس کریں

traces بھیجنے کا تیز ترین طریقہ یہ ہے کہ آپ اپنے [کوڈنگ ایجنٹ](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) (Claude Code، Codex، Cursor اور دیگر) کو اپنی ایپ میں instrumentation شامل کرنے دیں۔ اپنی پروجیکٹ ڈائریکٹری سے یہ چلائیں:

```shell
npx @arizeai/phoenix-cli setup
# یا، اگر Phoenix انسٹال ہو: px setup
```

سیٹ اپ آپ کے فریم ورک اور LLM فراہم کنندہ کا پتہ لگاتا ہے، درست [OpenInference](https://github.com/Arize-ai/openinference) instrumentation انسٹال کرتا ہے، اور trace ایکسپورٹ کو جوڑ دیتا ہے۔ کیا آپ اسے کوڈ میں سیٹ اپ کرنا پسند کریں گے؟ [ٹریسنگ دستاویزات](https://arize.com/docs/phoenix/tracing/llm-traces) دیکھیں۔

## انسانوں اور کوڈنگ ایجنٹس کے لیے

Phoenix کو اس طرح بنایا گیا ہے کہ اسے انسان اور AI کوڈنگ ایجنٹس دونوں یکساں طور پر چلا سکیں۔ تین انٹرفیسز ایجنٹس (Claude Code، Codex، Cursor اور دیگر) کو آپ کے traces، ڈیٹا سیٹس اور تجربات کے ساتھ کام کرنے دیتے ہیں:

- **[CLI](https://arize.com/docs/phoenix/sdk-api-reference/typescript/arizeai-phoenix-cli)** — `npx @arizeai/phoenix-cli` traces، ڈیٹا سیٹس اور تجربات حاصل کرتا ہے اور آپ کی ایپ میں instrumentation شامل کرتا ہے (`setup`)، تاکہ ایجنٹ ٹرمینل سے سیاق و سباق حاصل کر کے اس پر عمل کر سکے۔
- **[Skills](https://docs.anthropic.com/en/docs/claude-code/skills)** — [`.agents/skills/`](.agents/skills/) ایسے ورک فلوز پیک کرتا ہے جو ایجنٹس کو سکھاتے ہیں کہ Phoenix کے ساتھ ڈیبگ، جانچ اور ٹریس کیسے کریں۔
- **[ریموٹ MCP سرور](https://arize.com/docs/phoenix/integrations/remote-mcp)** — کسی بھی MCP کلائنٹ کو اپنے انسٹینس کے `/mcp` اینڈ پوائنٹ سے جوڑیں تاکہ براہ راست Phoenix سے کوئری کر سکیں۔

سیٹ اپ اور استعمال کے لیے [کوڈنگ ایجنٹس کی دستاویزات](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) دیکھیں۔

| Skill | تفصیل |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [phoenix-cli](.agents/skills/phoenix-cli/) | Phoenix CLI کے ذریعے LLM ایپلیکیشنز کو ڈیبگ کریں — traces حاصل کریں، خرابیوں کا تجزیہ کریں، تجربات کا جائزہ لیں، اور GraphQL API پر کوئری کریں |
| [phoenix-evals](.agents/skills/phoenix-evals/) | Phoenix کے ذریعے AI/LLM ایپلیکیشنز کے لیے evaluators بنائیں اور چلائیں |
| [phoenix-tracing](.agents/skills/phoenix-tracing/) | LLM ایپلیکیشنز کی ٹریسنگ کے لیے OpenInference کی semantic conventions اور instrumentation |

### ٹیلی میٹری

بطور ڈیفالٹ، Phoenix بنیادی ویب اینالیٹکس (مثلاً صفحات کے ویوز، UI کے ساتھ تعاملات) جمع کرتا ہے تاکہ ہمیں یہ سمجھنے میں مدد ملے کہ Phoenix کیسے استعمال ہوتا ہے اور پروڈکٹ کو بہتر بنایا جا سکے۔ **آپ کا کوئی بھی trace ڈیٹا، جانچ کے نتائج، یا کوئی حساس معلومات کبھی جمع نہیں کی جاتیں۔**

آپ یہ environment variable سیٹ کر کے ٹیلی میٹری سے دستبردار ہو سکتے ہیں: `PHOENIX_TELEMETRY_ENABLED=false`
