What the columns mean

label
what you called this run
task
which question was asked
trial
which repeat — every question is asked more than once
tokens
how long the conversation got. The model is re-sent the whole conversation every turn, so it only grows; this is its length at the end.
usd
what the run cost. Re-sent text is cached — charged once at a premium, then about a tenth of that on every turn after. Most of the bill is carrying the conversation, not writing the answer.
api time
seconds the model spent thinking and writing
tool time
seconds spent waiting on Phoenix to answer tool calls
turns
trips back to the model before it had an answer
tools
tool calls made
disc
how many of those were spent working out which tools exist — overhead before any real work
output
tokens the model wrote — its reasoning, plus any SQL
status
whether the reply contained the expected answer
route
the tools it called, in order, with consecutive repeats collapsed. Two runs of the same question can take very different routes, and this is usually what explains a gap in tokens or time between them.

The questions that were asked

Each was posed verbatim to every label, with the expected answer fixed in advance. "Answered" shows what each label actually replied.

What this is

An AI agent was asked questions about real trace data, reaching Phoenix over MCP. Same model, same questions, no system prompt, no built-in tools — so the only thing that varies is the tool surface. Each question is asked several times, because the agent does not take the same path twice.

What's measured is tokens: the text the model has to read and write. Tokens are the bill, and there is a hard limit on how many fit at once, so fewer is better — but only if the answer is still right. Every number below counts only runs that answered correctly.
