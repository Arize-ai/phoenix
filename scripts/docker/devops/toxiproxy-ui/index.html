Connection

Cut connection disables the proxy. Toxiproxy closes Phoenix's open database connections and refuses new ones. The button then reads Restore connection. Click it to enable the proxy again, so that it accepts new connections. The closed connections do not reopen: Phoenix must open new ones. Reset all enables the proxy and removes every toxic, which means no added delay.

Presets

A preset removes the active toxics, then adds its own. These are the same presets as scripts/toxiproxy-scenario.sh.

Latency

One direction delays only the responses from PostgreSQL to Phoenix, so a query round trip takes the latency once. Both directions delays the requests too, so a round trip takes the latency twice. A latency of 0 removes the delay.
