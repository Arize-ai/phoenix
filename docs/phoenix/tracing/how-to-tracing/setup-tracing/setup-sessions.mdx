If you use LangChain, Phoenix can read LangChain thread metadata as session metadata. Use `thread_id`, `session_id`, or `conversation_id`.
</Info>

A session is a group of traces that belong to the same conversation or thread. Each response can be its own trace, and Phoenix links those traces with the same `session.id`.

To associate traces together, set a stable session ID before the spans are created.

## Logging conversations

The examples below show how to attach the same session ID to multiple model calls.

<Tabs>

  <Tab title="Python" icon="python">

    Install Phoenix OTEL and the OpenAI instrumentor:

    ```bash
    pip install "arize-phoenix-otel>=0.16.0" openai openinference-instrumentation-openai
    ```

    <Note>
    Requires `arize-phoenix-otel` **0.16.0 or later** for `using_session` to be importable directly from `phoenix.otel`. On older versions, import it from `openinference.instrumentation`.
    </Note>

    Register tracing with auto-instrumentation, then wrap each model call with `using_session`.

    ```python
    import uuid

    from openai import OpenAI
    from phoenix.otel import register, using_session

    register(project_name="chatbot", auto_instrument=True)

    client = OpenAI()
    session_id = str(uuid.uuid4())

    def assistant(messages: list[dict], session_id: str):
        with using_session(session_id=session_id):
            response = client.chat.completions.create(
                model="gpt-4o-mini",
                messages=[
                    {"role": "system", "content": "You are a helpful assistant."},
                    *messages,
                ],
            )
        return response.choices[0].message

    messages = [
        {"role": "user", "content": "Hi, I'm Bob."}
    ]
    response = assistant(messages, session_id=session_id)
    messages = messages + [
        {"role": "assistant", "content": response.content or ""},
        {"role": "user", "content": "What's my name?"},
    ]
    response = assistant(messages, session_id=session_id)
    ```

  </Tab>

  <Tab title="TypeScript" icon="js">

    Install Phoenix OTEL and the OpenAI instrumentor:

    ```bash
    npm install @arizeai/phoenix-otel @arizeai/openinference-instrumentation-openai openai
    ```

    Register tracing and add the session ID to the active OpenTelemetry context.

    ```typescript
    import OpenAI from "openai";
    import {
      context,
      register,
      registerInstrumentations,
      setSession,
    } from "@arizeai/phoenix-otel";
    import { OpenAIInstrumentation } from "@arizeai/openinference-instrumentation-openai";

    register({ projectName: "chatbot" });

    const instrumentation = new OpenAIInstrumentation();
    instrumentation.manuallyInstrument(OpenAI);
    registerInstrumentations({ instrumentations: [instrumentation] });

    const client = new OpenAI();

    type Message = { role: "user" | "assistant" | "system"; content: string };

    async function assistant(params: {
      messages: Message[];
      sessionId: string;
    }) {
      return context.with(
        setSession(context.active(), { sessionId: params.sessionId }),
        async () => {
          const chatCompletion = await client.chat.completions.create({
            messages: params.messages,
            model: "gpt-4o-mini",
          });
          return chatCompletion.choices[0].message;
        }
      );
    }

    const sessionId = crypto.randomUUID();

    let messages: Message[] = [{ role: "user", content: "Hi, I'm Tim." }];

    const response = await assistant({
      messages,
      sessionId,
    });

    messages = [
      ...messages,
      { role: "assistant", content: response.content ?? "" },
      { role: "user", content: "What's my name?" },
    ];

    await assistant({
      messages,
      sessionId,
    });
    ```

## How to track sessions with LangChain

For LangChain, pass a session key in run metadata. The value should be the unique identifier for that conversation. Use one of these key names:

* `session_id`

* `thread_id`

* `conversation_id`.
