Make traces meaningful for your app. Auto-instrumentation captures standard AI work, but your app has context Phoenix cannot infer: session IDs, user IDs, customer tier, feature flags, prompt versions, and error details. This page shows how to add that context to spans.

If you still need to create spans, start with [Auto-instrumentation](/docs/phoenix/tracing/how-to-tracing/setup-tracing/setup-using-phoenix-otel) or [Manual instrumentation](/docs/phoenix/tracing/how-to-tracing/setup-tracing/instrument).

## Semantic conventions

[OpenInference semantic conventions](https://github.com/Arize-ai/openinference/blob/main/spec/semantic_conventions.md) are the standard attribute names Phoenix reads to render AI traces correctly. Use them when you set attributes yourself.

<Tabs>
  <Tab title="Python" icon="python">
    ```python
    from phoenix.otel import (
        OpenInferenceMimeTypeValues,
        OpenInferenceSpanKindValues,
        SpanAttributes,
    )

    span.set_attributes(
        {
            SpanAttributes.OPENINFERENCE_SPAN_KIND: OpenInferenceSpanKindValues.CHAIN.value,
            SpanAttributes.INPUT_VALUE: "Where is my order?",
            SpanAttributes.INPUT_MIME_TYPE: OpenInferenceMimeTypeValues.TEXT.value,
        }
    )
    ```
  </Tab>

  <Tab title="JS/TS" icon="js">
    ```typescript
    import {
      MimeType,
      OpenInferenceSpanKind,
      SemanticConventions,
    } from "@arizeai/phoenix-otel";

    span.setAttributes({
      [SemanticConventions.OPENINFERENCE_SPAN_KIND]: OpenInferenceSpanKind.CHAIN,
      [SemanticConventions.INPUT_VALUE]: "Where is my order?",
      [SemanticConventions.INPUT_MIME_TYPE]: MimeType.TEXT,
    });
    ```
  </Tab>

  <Tab title="Go" icon="golang">
    ```go
    import (
        semconv "github.com/Arize-ai/openinference/go/openinference-semantic-conventions"
        "go.opentelemetry.io/otel/attribute"
    )

    span.SetAttributes(
        attribute.String(semconv.OpenInferenceSpanKind, semconv.SpanKindChain),
        attribute.String(semconv.InputValue, "Where is my order?"),
        attribute.String(semconv.InputMimeType, semconv.MimeTypeText),
    )
    ```
  </Tab>
</Tabs>

## Structured inputs and outputs

Set `input.value` and `output.value` for the span table. Set MIME types when the value is JSON, text, or another structured format.

For chat-style LLM spans, also use `llm.input_messages.*` and `llm.output_messages.*` so Phoenix can show message roles and content. See [OpenInference span kinds](/docs/phoenix/tracing/concepts-tracing/otel-openinference/span-kinds) for the message format.

<Tabs>
  <Tab title="Python" icon="python">
    ```python
    import json

    from phoenix.otel import OpenInferenceMimeTypeValues, SpanAttributes

    span.set_attributes(
        {
            SpanAttributes.INPUT_VALUE: json.dumps({"question": question}),
            SpanAttributes.INPUT_MIME_TYPE: OpenInferenceMimeTypeValues.JSON.value,
            SpanAttributes.OUTPUT_VALUE: answer,
            SpanAttributes.OUTPUT_MIME_TYPE: OpenInferenceMimeTypeValues.TEXT.value,
        }
    )
    ```
  </Tab>

  <Tab title="JS/TS" icon="js">
    ```typescript
    import { MimeType, SemanticConventions } from "@arizeai/phoenix-otel";

    span.setAttributes({
      [SemanticConventions.INPUT_VALUE]: JSON.stringify({ question }),
      [SemanticConventions.INPUT_MIME_TYPE]: MimeType.JSON,
      [SemanticConventions.OUTPUT_VALUE]: answer,
      [SemanticConventions.OUTPUT_MIME_TYPE]: MimeType.TEXT,
    });
    ```
  </Tab>

  <Tab title="Go" icon="golang">
    ```go
    import (
        "encoding/json"

        semconv "github.com/Arize-ai/openinference/go/openinference-semantic-conventions"
        "go.opentelemetry.io/otel/attribute"
    )

    inputJSON, _ := json.Marshal(map[string]string{"question": question})

    span.SetAttributes(
        attribute.String(semconv.InputValue, string(inputJSON)),
        attribute.String(semconv.InputMimeType, semconv.MimeTypeJSON),
        attribute.String(semconv.OutputValue, answer),
        attribute.String(semconv.OutputMimeType, semconv.MimeTypeText),
    )
    ```
  </Tab>
</Tabs>

For tool calls, retrieval documents, and multimodal content, use the matching OpenInference attributes. See [OpenInference span kinds](/docs/phoenix/tracing/concepts-tracing/otel-openinference/span-kinds) and [Capture multimodal traces](/docs/phoenix/tracing/how-to-tracing/advanced/multimodal-tracing).

## Custom attributes and metadata

Use custom attributes for single-span values you want to filter or group by, such as customer tier, environment, feature flag, or A/B test variant. Use metadata for request-wide JSON context that should travel with child spans.

| Use | Best for | Example |
| :-- | :------- | :------ |
| Custom attribute | A filterable value on one span | `mycompany.customer_tier` |
| Metadata | Request-wide JSON context inherited by child spans | `{"request_id": "req-123"}` |

<Tabs>
  <Tab title="Python" icon="python">
    ```python
    from opentelemetry import trace
    from phoenix.otel import using_metadata

    current_span = trace.get_current_span()
    current_span.set_attribute("mycompany.customer_tier", "enterprise")
    current_span.set_attribute("mycompany.ab_variant", "v2")

    with using_metadata({"request_id": request_id, "pipeline_version": "2026-09"}):
        run_agent()
    ```
  </Tab>

  <Tab title="JS/TS" icon="js">
    ```typescript
    import {
      context,
      setAttributes,
      setMetadata,
    } from "@arizeai/phoenix-otel";

    const ctx = setMetadata(
      setAttributes(context.active(), {
        "mycompany.customer_tier": "enterprise",
        "mycompany.ab_variant": "v2",
      }),
      { requestId, pipelineVersion: "2026-09" }
    );

    await context.with(ctx, async () => runAgent());
    ```
  </Tab>

  <Tab title="Go" icon="golang">
    ```go
    import (
        "encoding/json"

        instrumentation "github.com/Arize-ai/openinference/go/openinference-instrumentation"
        "go.opentelemetry.io/otel/attribute"
    )

    metadataJSON, _ := json.Marshal(map[string]string{
        "request_id": requestID,
        "pipeline_version": "2026-09",
    })

    ctx = instrumentation.WithMetadata(ctx, string(metadataJSON))
    span.SetAttributes(
        attribute.String("mycompany.customer_tier", "enterprise"),
        attribute.String("mycompany.ab_variant", "v2"),
    )
    ```
  </Tab>
</Tabs>

Best practice: prefix custom attributes with your company or app name, for example `mycompany.customer_tier`, so they do not clash with OpenInference or OpenTelemetry attributes.

## Sessions, users, and tags

Set session, user, metadata, and tags on the active context before the traced work runs. OpenInference instrumentors and helpers read that context and attach the attributes to spans created inside it.

<Tabs>
  <Tab title="Python" icon="python">
    ```python
    from phoenix.otel import using_attributes

    with using_attributes(
        session_id="session-abc",
        user_id="user-123",
        metadata={"tenant": "acme"},
        tags=["production", "checkout"],
    ):
        run_agent()
    ```
  </Tab>

  <Tab title="JS/TS" icon="js">
    ```typescript
    import {
      context,
      setMetadata,
      setSession,
      setTags,
      setUser,
    } from "@arizeai/phoenix-otel";

    let ctx = setSession(context.active(), { sessionId: "session-abc" });
    ctx = setUser(ctx, { userId: "user-123" });
    ctx = setMetadata(ctx, { tenant: "acme" });
    ctx = setTags(ctx, ["production", "checkout"]);

    await context.with(ctx, async () => runAgent());
    ```
  </Tab>

  <Tab title="Go" icon="golang">
    ```go
    import (
        "encoding/json"

        instrumentation "github.com/Arize-ai/openinference/go/openinference-instrumentation"
    )

    metadataJSON, _ := json.Marshal(map[string]string{"tenant": "acme"})

    ctx = instrumentation.WithSession(ctx, "session-abc")
    ctx = instrumentation.WithUser(ctx, "user-123")
    ctx = instrumentation.WithMetadata(ctx, string(metadataJSON))
    ctx = instrumentation.WithTags(ctx, "production", "checkout")
    ```
  </Tab>
</Tabs>

Use the same `session.id` for every turn in a conversation. See [Set up sessions](/docs/phoenix/tracing/how-to-tracing/setup-tracing/setup-sessions).

If you create raw OpenTelemetry spans inside that context, copy the propagated attributes onto the span yourself. OpenInference instrumentors and `OITracer` do this automatically. See [OpenInference context managers](/docs/phoenix/tracing/concepts-tracing/otel-openinference/context-managers) and [TypeScript context attributes](/docs/phoenix/sdk-api-reference/typescript/packages/phoenix-otel/context-attributes).

## Prompt templates

Prompt-template attributes tell Phoenix which template, version, and variables produced an LLM call. Set them before the model call, because most apps render the final prompt before sending it to the provider.

<Tabs>
  <Tab title="Python" icon="python">
    ```python
    from phoenix.otel import using_prompt_template

    with using_prompt_template(
        template="Answer the question for {persona}: {question}",
        variables={"persona": "support agent", "question": question},
        version="v1.0",
    ):
        response = run_chat_completion(question)
    ```
  </Tab>

  <Tab title="JS/TS" icon="js">
    ```typescript
    import { context, setPromptTemplate } from "@arizeai/phoenix-otel";

    const ctx = setPromptTemplate(context.active(), {
      template: "Answer the question for {{persona}}: {{question}}",
      variables: { persona: "support agent", question },
      version: "v1.0",
    });

    await context.with(ctx, async () => runChatCompletion(question));
    ```
  </Tab>

  <Tab title="Go" icon="golang">
    Go does not have a prompt-template context helper today. Set the attributes directly on the LLM span.

    ```go
    import (
        "encoding/json"

        semconv "github.com/Arize-ai/openinference/go/openinference-semantic-conventions"
        "go.opentelemetry.io/otel/attribute"
    )

    variablesJSON, _ := json.Marshal(map[string]string{
        "persona": "support agent",
        "question": question,
    })

    span.SetAttributes(
        attribute.String(semconv.LLMPromptTemplate, "Answer the question for {persona}: {question}"),
        attribute.String(semconv.LLMPromptTemplateVersion, "v1.0"),
        attribute.String(semconv.LLMPromptTemplateVariables, string(variablesJSON)),
    )
    ```
  </Tab>
</Tabs>

## Status, events, and exceptions

Use span status to mark success or failure, events to mark important moments, and recorded exceptions to preserve error details.

<Tabs>
  <Tab title="Python" icon="python">
    ```python
    from opentelemetry import trace
    from opentelemetry.trace import Status, StatusCode

    span = trace.get_current_span()
    span.add_event("retrieval.cache_miss", {"request.id": request_id})

    try:
        result = run_step()
    except Exception as error:
        span.record_exception(error)
        span.set_status(Status(StatusCode.ERROR))
        raise
    else:
        span.set_status(Status(StatusCode.OK))
    ```
  </Tab>

  <Tab title="JS/TS" icon="js">
    ```typescript
    import { SpanStatusCode, trace } from "@arizeai/phoenix-otel";

    const span = trace.getActiveSpan();
    span?.addEvent("retrieval.cache_miss", { "request.id": requestId });

    try {
      const result = await runStep();
    } catch (error) {
      span?.recordException(error as Error);
      span?.setStatus({ code: SpanStatusCode.ERROR });
      throw error;
    }

    span?.setStatus({ code: SpanStatusCode.OK });
    ```
  </Tab>

  <Tab title="Go" icon="golang">
    ```go
    import (
        "go.opentelemetry.io/otel/attribute"
        "go.opentelemetry.io/otel/codes"
        "go.opentelemetry.io/otel/trace"
    )

    span := trace.SpanFromContext(ctx)
    span.AddEvent("retrieval.cache_miss", trace.WithAttributes(
        attribute.String("request.id", requestID),
    ))

    if err := runStep(); err != nil {
        span.RecordError(err)
        span.SetStatus(codes.Error, err.Error())
        return err
    }

    span.SetStatus(codes.Ok, "")
    ```
  </Tab>
</Tabs>

If the data arrives after the span has ended, log it as a note or annotation instead of trying to mutate the original span. See [Annotate with the client](/docs/phoenix/tracing/how-to-tracing/feedback-and-annotations/capture-feedback).

## Span processing

The Python snippets in these docs use `SimpleSpanProcessor` by default through `register()`. It exports each span as it is created, which is convenient while developing.

Use batching in production to reduce export overhead:

```python
from phoenix.otel import register

tracer_provider = register(
    project_name="my-llm-app",
    batch=True,
)
```

For TypeScript, `@arizeai/phoenix-otel` uses batching by default. Set `batch: false` only when you need immediate export for local debugging.

```typescript
import { register } from "@arizeai/phoenix-otel";

const provider = register({
  projectName: "my-llm-app",
  batch: false,
});
```
