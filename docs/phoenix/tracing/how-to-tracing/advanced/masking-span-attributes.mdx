Use masking when spans include data that Phoenix should not store. OpenInference applies these rules before spans are exported, so masked values do not reach Phoenix.

Masking can hide broad OpenInference fields, such as inputs, outputs, prompts, tool definitions, images, and embedding vectors. Redaction can rewrite specific values inside attributes, such as email addresses or other PII.

## Choose a method

| If you need to... | Use... |
| :--- | :--- |
| Apply the same rule in every environment | Environment variables |
| Keep masking next to one instrumentor setup | `TraceConfig` in code |
| Redact specific text inside attributes | A custom exporter |
| Skip a code path entirely | `suppress_tracing` |

If you set a value in both code and the environment, code wins. If neither is set, OpenInference uses the default value.

## Environment variables

Set environment variables before your app initializes tracing.

```bash
export OPENINFERENCE_HIDE_INPUTS=true
export OPENINFERENCE_HIDE_OUTPUTS=true
export OPENINFERENCE_HIDE_INPUT_IMAGES=true
export OPENINFERENCE_BASE64_IMAGE_MAX_LENGTH=8000
```

Common options:

| Environment variable | Effect | Default |
| :--- | :--- | :--- |
| `OPENINFERENCE_HIDE_INPUTS` | Hides span input values, input messages, prompts, and LLM tools | `false` |
| `OPENINFERENCE_HIDE_OUTPUTS` | Hides span output values and output messages | `false` |
| `OPENINFERENCE_HIDE_INPUT_MESSAGES` | Hides all LLM input messages | `false` |
| `OPENINFERENCE_HIDE_OUTPUT_MESSAGES` | Hides all LLM output messages | `false` |
| `OPENINFERENCE_HIDE_INPUT_IMAGES` | Hides images from LLM input messages and span-level input images | `false` |
| `OPENINFERENCE_HIDE_INPUT_TEXT` | Redacts text in LLM input messages | `false` |
| `OPENINFERENCE_HIDE_OUTPUT_TEXT` | Redacts text in LLM output messages | `false` |
| `OPENINFERENCE_HIDE_EMBEDDING_VECTORS` | Hides embedding vectors | `false` |
| `OPENINFERENCE_HIDE_PROMPTS` | Redacts legacy `llm.prompts` attributes | `false` |
| `OPENINFERENCE_HIDE_LLM_TOOLS` | Hides tool definitions advertised to the LLM | `false` |
| `OPENINFERENCE_BASE64_IMAGE_MAX_LENGTH` | Redacts base64 image URLs longer than this many characters | `32000` |

<Note>
Python also supports `OPENINFERENCE_HIDE_LLM_INVOCATION_PARAMETERS`, `OPENINFERENCE_HIDE_CHOICES`, `OPENINFERENCE_HIDE_EMBEDDINGS_TEXT`, and `OPENINFERENCE_HIDE_EMBEDDINGS_VECTORS`.
</Note>

## Configure in code

Use code when one instrumentor needs different masking than the rest of the process. The examples below use OpenAI, but supported OpenInference instrumentors follow the same pattern.

<Tabs>
  <Tab title="Python" icon="python">

    ```python
    from openinference.instrumentation import TraceConfig
    from openinference.instrumentation.openai import OpenAIInstrumentor
    from phoenix.otel import register

    tracer_provider = register(project_name="redacted-app")

    config = TraceConfig(
        hide_inputs=True,
        hide_outputs=True,
        hide_input_images=True,
        hide_llm_tools=True,
        base64_image_max_length=8_000,
    )

    OpenAIInstrumentor().instrument(
        tracer_provider=tracer_provider,
        config=config,
    )
    ```

  </Tab>

  <Tab title="TypeScript" icon="js">

    ```typescript
    import OpenAI from "openai";
    import { register, registerInstrumentations } from "@arizeai/phoenix-otel";
    import { OpenAIInstrumentation } from "@arizeai/openinference-instrumentation-openai";

    register({ projectName: "redacted-app" });

    const traceConfig = {
      hideInputs: true,
      hideLLMTools: true,
      hideInputImages: true,
      base64ImageMaxLength: 8_000,
    };

    const instrumentation = new OpenAIInstrumentation({ traceConfig });
    instrumentation.manuallyInstrument(OpenAI);

    registerInstrumentations({
      instrumentations: [instrumentation],
    });
    ```

  </Tab>

  <Tab title="Go" icon="golang">

    Use `instrumentation.TraceConfig` and pass it to the provider instrumentor with `WithTraceConfig`.

    ```go
    import (
        "github.com/openai/openai-go"
        "github.com/openai/openai-go/option"

    client := openai.NewClient(

                HideInputs: true,
    ```

## Redact specific PII

Use a custom exporter when you need to keep the span but rewrite sensitive text inside attributes. Add the exporter before your app starts traced work.

```python
import re
from collections.abc import Sequence
from typing import Any

from opentelemetry.sdk.trace import ReadableSpan
from opentelemetry.sdk.trace.export import SpanExporter, SpanExportResult
from phoenix.otel import BatchSpanProcessor, HTTPSpanExporter, register


PATTERNS = [
    (re.compile(r"\b[\w.+-]+@[\w-]+\.[\w.-]+\b"), "[email]"),
    (re.compile(r"\b\d{3}-\d{2}-\d{4}\b"), "[ssn]"),
]


def redact_text(value: str) -> str:
    for pattern, replacement in PATTERNS:
        value = pattern.sub(replacement, value)
    return value


def redact_value(value: Any) -> Any:
    if isinstance(value, str):
        return redact_text(value)
    if isinstance(value, (list, tuple)):
        return [redact_text(item) if isinstance(item, str) else item for item in value]
    return value


def redact_span(span: ReadableSpan) -> ReadableSpan:
    attributes = {
        key: redact_value(value)
        for key, value in (span.attributes or {}).items()
    }
    return ReadableSpan(
        name=span.name,
        context=span.context,
        parent=span.parent,
        resource=span.resource,
        attributes=attributes,
        events=span.events,
        links=span.links,
        kind=span.kind,
        status=span.status,
        start_time=span.start_time,
        end_time=span.end_time,
        instrumentation_scope=span.instrumentation_scope,
    )


class RedactingSpanExporter(SpanExporter):
    def __init__(self, exporter: SpanExporter) -> None:
        self._exporter = exporter

    def export(self, spans: Sequence[ReadableSpan]) -> SpanExportResult:
        return self._exporter.export([redact_span(span) for span in spans])

    def shutdown(self) -> None:
        self._exporter.shutdown()

    def force_flush(self, timeout_millis: int = 30000) -> bool:
        return self._exporter.force_flush(timeout_millis=timeout_millis)


tracer_provider = register(project_name="redacted-app")
tracer_provider.add_span_processor(
    BatchSpanProcessor(
        span_exporter=RedactingSpanExporter(HTTPSpanExporter())
    )
)
```

Add more patterns to `PATTERNS` for your own data. If regex is not enough, call a PII detector inside `redact_text` and return the redacted string.

## What masking does not do

Masking changes span attributes before export. It does not change the request your app sends to the model provider.

For code that should not be traced at all, use [suppression](/docs/phoenix/tracing/how-to-tracing/advanced#suppress-tracing).
