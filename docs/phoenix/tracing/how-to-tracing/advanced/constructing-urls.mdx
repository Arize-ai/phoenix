Phoenix provides redirect URLs that let you link to resources using identifiers you already know, such as a project name or an OpenTelemetry trace ID. You do not need to look up Phoenix's internal IDs first.

Use redirect URLs for bookmarks, dashboards, runbooks, and CI jobs.

## URL patterns

All redirect URLs follow the pattern `{phoenix_host}/redirects/...` and resolve to the appropriate Phoenix page.

| Resource | URL pattern | Identifier |
| --- | --- | --- |
| Project | `/redirects/projects/{project_name}` | Project name, such as `default` |
| Trace | `/redirects/traces/{trace_id}` | OpenTelemetry trace ID |
| Span | `/redirects/spans/{span_id}` | OpenTelemetry span ID |
| Session | `/redirects/sessions/{session_id}` | Session ID |
| Prompt tag | `/redirects/prompts/{prompt_id}/tags/{tag_name}` | Prompt global ID and tag name |
| Dataset example | `/redirects/datasets/{dataset_id}/examples/{external_id}` | Dataset global ID and example external ID |

## Examples

### Link to a project by name

```text
https://my-phoenix.example.com/redirects/projects/default
```

Phoenix resolves the project named `default` and redirects to its project page. Use this when you know the project name from your `PHOENIX_PROJECT_NAME` environment variable or `register()` call.

### Link to a trace by OpenTelemetry trace ID

```text
https://my-phoenix.example.com/redirects/traces/abc123def456
```

Phoenix redirects to the trace detail view. The trace ID is the same one you see in your OpenTelemetry SDK output or logs.

### Link to a span by OpenTelemetry span ID

```text
https://my-phoenix.example.com/redirects/spans/789abc012def
```

Phoenix redirects to the trace view with the span selected.

### Link to a session by session ID

```text
https://my-phoenix.example.com/redirects/sessions/user-session-42
```

Phoenix redirects to the session detail view within its parent project.

### Link to a dataset example by external ID

```text
https://my-phoenix.example.com/redirects/datasets/RGF0YXNldDox/examples/customer-refund-42
```

Phoenix resolves the example's external ID within the dataset and redirects to that example.

## Error handling

If the identifier doesn't match any existing resource, Phoenix displays an error page. The resource may have been deleted, or the identifier may be misspelled.

<Tip>
URL-encode names and IDs with special characters, such as spaces: `/redirects/projects/my%20project`.
</Tip>
