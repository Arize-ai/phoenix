## Download all spans as a dataframe

Use `get_spans_dataframe` when you want to filter or join spans locally with pandas.

```python
from phoenix.client import Client

client = Client()

# Download all spans from your default project
client.spans.get_spans_dataframe()

# Download all spans from a specific project
client.spans.get_spans_dataframe(project_identifier="my-project")
```

## Run span queries

Use `SpanQuery` when you want Phoenix to filter or reshape spans before returning a dataframe.

<Check>
The `.where()` filter expression uses the same language as the filter bar in the Phoenix dashboard. See the [Filter Expressions](/docs/phoenix/tracing/how-to-tracing/filter-expressions) reference for the full language. It can help to test your filter in the dashboard before moving it to code.

</Check>

The following query pulls all retriever spans and selects the input value. The result is a dataframe with the input values for all retriever spans.

```python
from phoenix.client import Client
from phoenix.trace.dsl import SpanQuery

client = Client()

query = SpanQuery().where(
    # Filter for the `RETRIEVER` span kind.
    # The filter condition is a valid Python boolean expression.
    "span_kind == 'RETRIEVER'",
).select(
    # Extract the span attribute `input.value`, which contains the query for the
    # retriever. Rename it as the `input` column in the output dataframe.
    input="input.value",
)

# The Phoenix client can run this query and return the dataframe.
client.spans.get_spans_dataframe(query=query)
```

<Info>
**Dataframe index** By default, the result dataframe is indexed by `span_id`. If `.explode()` is used, the index from the exploded list is added to create a multi-index on the result dataframe. For the special `retrieval.documents` span attribute, the added index is renamed as `document_position`.

</Info>

### Specify a time range

By default, queries collect spans from your Phoenix instance up to the request limit. Use `start_time` and `end_time` when you want a narrower time window.

```python
from phoenix.client import Client
from phoenix.trace.dsl import SpanQuery
from datetime import datetime, timedelta

client = Client()

# Get spans from the last 7 days only
start = datetime.now() - timedelta(days=7)

# Get spans to exclude the last 24 hours
end = datetime.now() - timedelta(days=1)

phoenix_df = client.spans.get_spans_dataframe(start_time=start, end_time=end)
```

### Specify a project

By default, queries run against the default project or the project set by `PHOENIX_PROJECT`. `PHOENIX_PROJECT_NAME` is still supported as an alias. Pass `project_identifier` when you want a specific project by name or ID.

```python
from phoenix.client import Client
from phoenix.trace.dsl import SpanQuery

client = Client()

# Get spans from a project
client.spans.get_spans_dataframe(project_identifier="my-project")

# Use SpanQuery with a specific project
query = SpanQuery().where("span_kind == 'CHAIN'").select(input="input.value")
client.spans.get_spans_dataframe(query=query, project_identifier="my-project")
```

### Query retrieved documents

You can extract retrieved documents into a dataframe with one row per retrieved document. In the example below, `input` is the retriever query, `context` is the document text, and `document_position` is the zero-based index in each span's list of retrieved documents.

The dataframe can be used directly as input for [pre-built evaluations](/docs/phoenix/evaluation/pre-built-metrics).

| context.span\_id | document\_position | input                                            | context                                                |
| :---------------- | :------------------ | :------------------------------------------------ | :-------------------------------------------------------- |
| 5B8EF798A381     | 0                  | What was the author's motivation for writing ... | In fact, I decided to write a book about ...             |
| 5B8EF798A381     | 1                  | What was the author's motivation for writing ... | I started writing essays again, and wrote a bunch of ... |
| ...              | ...                | ...                                              | ...                                                      |
| E19B7EC3GG02     | 0                  | What did the author learn about ...              | The good part was that I got paid huge amounts of ...    |

Use `.explode()` to split each retrieved document into its own row.

```python expandable
from phoenix.client import Client
from phoenix.trace.dsl import SpanQuery

client = Client()

query = SpanQuery().where(
    # Filter for the `RETRIEVER` span kind.
    # The filter condition is a valid Python boolean expression.
    "span_kind == 'RETRIEVER'",
).select(
    # Extract the span attribute `input.value`, which contains the query for the
    # retriever. Rename it as the `input` column in the output dataframe.
    input="input.value",
).explode(
    # Specify the span attribute `retrieval.documents` which contains a list of
    # objects and explode the list. Extract the `document.content` attribute from
    # each object and rename it as the `context` column in the output dataframe.
    "retrieval.documents",
    context="document.content",
)

# The Phoenix client can run this query and return the dataframe.
client.spans.get_spans_dataframe(query=query)
```

### Explode attributes

Add more fields to `.explode()` when you want each retrieved document row to include more document attributes. The example below includes both the document text and the document score. Use keyword arguments to name the output columns.

```python
query = SpanQuery().explode(
    "retrieval.documents",
    context="document.content",
    score="document.score",
)
```

### Apply filters

The `.where()` method accepts a filter expression and returns only the spans that match it. The same expressions work in the span and trace filter bars in the Phoenix UI.

```python
query = SpanQuery().where(
    "span_kind == 'RETRIEVER' and 'programming' in input.value"
)
```

The filter expression reference covers attribute access, annotation access, substring search, `is None`, and operators for spans, traces, and sessions.

### Extract attributes

Select span attributes by listing them inside `.select()`.

```python
query = SpanQuery().select(
    "input.value",
    "output.value",
)
```

#### Rename output columns

Use keyword arguments to rename columns in the dataframe. The example below returns two columns named `input` and `output` instead of the original attribute names.

```python
query = SpanQuery().select(
    input="input.value",
    output="output.value",
)
```

#### Use arbitrary output column names

Use Python dictionary unpacking when an output column name contains spaces or symbols.

```python
query = SpanQuery().select(**{
    "Value (Input)": "input.value",
    "Value (Output)": "output.value",
})
```

### Advanced usage

#### Concatenate values

Use `.concat()` when you want one row per span and a single column that joins values from a list attribute. The default separator is two newline characters. The example below joins all `document.content` values into a column named `context`.

```python
query = SpanQuery().concat(
    "retrieval.documents",
    context="document.content",
)
```

#### Use a custom separator

Pass a custom separator when you want to control how the values are joined.

```python
query = SpanQuery().concat(
    "retrieval.documents",
    context="document.content",
).with_concat_separator(
    separator="\n************\n",
)
```

#### Use parent ID as the index

Set the child dataframe index to the parent span ID when you want to join child spans back to their parent spans. Phoenix treats a selected column named `span_id` as the output dataframe index.

```python
query = SpanQuery().select(
    span_id="parent_id",
    output="output.value",
)
```

#### Join a span to its parent

Run one query for parent spans and one query for child spans, then join the resulting dataframes with pandas.

```python
import pandas as pd
from phoenix.client import Client
from phoenix.trace.dsl import SpanQuery

client = Client()

parent_df = client.spans.get_spans_dataframe(query=query_for_parent_spans)
child_df = client.spans.get_spans_dataframe(query=query_for_child_spans)

pd.concat(
    [parent_df, child_df],
    axis=1,        # joining on the row indices
    join="inner",  # inner-join by the indices of the dataframes
)
```

### Use data for evaluation

#### Extract input and output from LLM spans

To learn more about extracting span attributes, see [Extract attributes](/docs/phoenix/tracing/how-to-tracing/importing-and-exporting-traces/extract-data-from-spans#extract-attributes).

```python
from phoenix.client import Client
from phoenix.trace.dsl import SpanQuery

client = Client()

query = SpanQuery().where(
    "span_kind == 'LLM'",
).select(
    input="input.value",
    output="output.value",
)

# The Phoenix client can run this query and return a dataframe.
client.spans.get_spans_dataframe(query=query)
```

### Correctness evaluations

Use the following query to build a dataframe for [Correctness evaluations](/docs/phoenix/evaluation/pre-built-metrics/correctness). The query joins root span input and output with retrieved document context.

```python expandable
import pandas as pd
from phoenix.client import Client
from phoenix.trace.dsl import SpanQuery

client = Client()

query_for_root_span = SpanQuery().where(
    "parent_id is None",   # Filter for root spans
).select(
    input="input.value",   # Input contains the user's question
    output="output.value", # Output contains the LLM's answer
)

query_for_retrieved_documents = SpanQuery().where(
    "span_kind == 'RETRIEVER'",  # Filter for RETRIEVER span
).select(
    # Rename parent_id as span_id. This turns the parent_id
    # values into the index of the output dataframe.
    span_id="parent_id",
).concat(
    "retrieval.documents",
    context="document.content",
)

root_df = client.spans.get_spans_dataframe(query=query_for_root_span)
docs_df = client.spans.get_spans_dataframe(query=query_for_retrieved_documents)

# Perform an inner join on the two sets of spans.
pd.concat(
    [root_df, docs_df],
    axis=1,
    join="inner",
)
```

The output dataframe has the question in `input`, the answer in `output`, and the joined retrieved documents in `context`.

| context.span\_id | input                               | output                     | context                                            |
| :---------------- | :----------------------------------- | :-------------------------- | :---------------------------------------------------- |
| CDBC4CE34        | What was the author's trick for ... | The author's trick for ... | Even then it took me several years to understand ... |
| ...              | ...                                 | ...                        | ...                                                  |
