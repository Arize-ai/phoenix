Use this page when traces are already in Phoenix and you want to analyze them in code.

You will learn how to export spans to a dataframe, query the span fields you need, and include annotations such as human feedback or evaluation results.

Phoenix gives you two main export paths:

| Method | Use when |
|---|---|
| `get_spans_dataframe` | You want all matching spans as a pandas dataframe. |
| `SpanQuery` | You want Phoenix to filter, select, explode, or concatenate span attributes before returning a dataframe. |

## Connect to Phoenix

<ConnectToPhoenixPython />

```python
from phoenix.client import Client

client = Client()
```

## Export spans to a dataframe

Use `get_spans_dataframe` when you want to filter, join, or evaluate spans locally with pandas.

```python
from phoenix.client import Client

client = Client()

# Download spans from the default project
spans = client.spans.get_spans_dataframe()

# Download spans from a specific project
spans = client.spans.get_spans_dataframe(project_identifier="my-project")
```

Limit exports by time when you only need a recent window.

```python
from datetime import datetime, timedelta
from phoenix.client import Client

client = Client()

start = datetime.now() - timedelta(days=7)
end = datetime.now()

spans = client.spans.get_spans_dataframe(start_time=start, end_time=end)
```

## Query spans

Use `SpanQuery` when you want Phoenix to filter or reshape spans before returning a dataframe.

<Check>
The `.where()` filter expression uses the same language as the Phoenix filter bar. See [Filter Expressions](/docs/phoenix/tracing/how-to-tracing/filter-expressions) for the full reference.
</Check>

<Info>
By default, result dataframes are indexed by `span_id`. If you use `.explode()`, Phoenix adds the exploded list index to the dataframe index. For `retrieval.documents`, that added index is named `document_position`.
</Info>

This query returns retriever spans with their input value.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

query = (
    SpanQuery()
    .where("span_kind == 'RETRIEVER'")
    .select("input.value")
    .rename(**{"input.value": "input"})
)

retriever_spans = client.spans.get_spans_dataframe(query=query)
```

Use the same pattern to combine filters, selected fields, and output column names.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

query = (
    SpanQuery()
    .where("span_kind == 'RETRIEVER' and 'programming' in input.value")
    .select("input.value", "output.value")
    .rename(**{"input.value": "input", "output.value": "output"})
)

matching_spans = client.spans.get_spans_dataframe(query=query)
```

## Extract retrieved documents

Use `.explode()` when a span attribute contains a list. The example below returns one row per retrieved document.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

query = (
    SpanQuery()
    .where("span_kind == 'RETRIEVER'")
    .select("input.value")
    .rename(**{"input.value": "input"})
    .explode(
        "retrieval.documents",
        context="document.content",
        score="document.score",
    )
)

retrieved_documents = client.spans.get_spans_dataframe(query=query)
```

## Join spans for evaluation

Run separate queries when evaluation data lives on different spans, then join the dataframes with pandas.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

root_query = (
    SpanQuery()
    .where("parent_id is None")
    .select("input.value", "output.value")
    .rename(**{"input.value": "input", "output.value": "output"})
)

retriever_query = (
    SpanQuery()
    .where("span_kind == 'RETRIEVER'")
    .concat("retrieval.documents", context="document.content")
    .with_index("parent_id")
)

root_spans = client.spans.get_spans_dataframe(query=root_query)
retriever_context = client.spans.get_spans_dataframe(query=retriever_query)

evaluation_data = root_spans.join(retriever_context, how="inner")
```

Use the resulting dataframe with [pre-built evaluations](/docs/phoenix/evaluation/pre-built-metrics) such as correctness or retrieval relevance.

## SpanQuery patterns

Use these methods together when you need more control over the dataframe shape.

| Method | What it does |
|---|---|
| `.where("span_kind == 'LLM'")` | Filters spans before data is returned. |
| `.select("input.value")` | Selects span attributes. |
| `.rename(**{"input.value": "input"})` | Renames output columns. |
| `.explode("retrieval.documents", context="document.content")` | Returns one row per item in a list attribute. |
| `.concat("retrieval.documents", context="document.content")` | Keeps one row per span and joins list values into one column. |
| `.with_index("parent_id")` | Sets the dataframe index so child spans can be joined to parent spans. |

`project_identifier` can be a project name or ID. If you omit it, Phoenix uses the default project or the project set by `PHOENIX_PROJECT`.

## Export annotated spans

Use annotation filters when you want spans that already have human feedback or evaluator results. You can filter by annotation presence, score, or label.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

query = SpanQuery().where("annotations['correctness']")
# query = SpanQuery().where("annotations['correctness'].score == 1")
# query = SpanQuery().where("annotations['correctness'].label == 'correct'")

spans = client.spans.get_spans_dataframe(
    query=query,
    project_identifier="default",
)
```

To filter by trace-level annotations, use `trace_annotations`.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

query = SpanQuery().where("trace_annotations['quality'].score >= 0.5")

spans = client.spans.get_spans_dataframe(
    query=query,
    project_identifier="default",
)
```

Pull the matching span annotations and join them with the span dataframe.

```python
annotations = client.spans.get_span_annotations_dataframe(
    spans_dataframe=spans,
    project_identifier="default",
)

annotated_spans = annotations.join(spans, how="left")
```

You can also fetch annotations by span ID.

```python
annotations = client.spans.get_span_annotations_dataframe(
    span_ids=list(spans.index),
    project_identifier="default",
)
```

## Learn more

- **Filter spans before export:** use the same filter language in the Phoenix UI and in `SpanQuery`. See [Filter Expressions](/docs/phoenix/tracing/how-to-tracing/filter-expressions).
- **Pull traces from the terminal:** use the CLI when you want JSON output for debugging, shell scripts, or handoff to a coding agent. See [Retrieve traces with the CLI](/docs/phoenix/tracing/how-to-tracing/importing-and-exporting-traces/retrieve-traces-via-cli).

- **Move trace data into Phoenix:** use [Import existing traces](/docs/phoenix/tracing/how-to-tracing/importing-and-exporting-traces/importing-existing-traces) when span data starts outside Phoenix.
