Use this page when you already have trace data somewhere else and want to bring it into Phoenix. This page is not for instrumenting a new app.

There are two paths:

- Upload spans into a Phoenix project when you have a dataframe of [OpenInference](/docs/phoenix/resources/openinference) spans.
- Open saved traces locally when you have a saved trace dataframe and want to inspect it in a temporary Phoenix app.

## Upload spans to an existing Phoenix project

Use `log_spans_dataframe` when you have a dataframe of spans and want to write those spans to a Phoenix project.

```python
from phoenix.client import Client
from phoenix.client.exceptions import SpanCreationError

client = Client()

try:
    client.spans.log_spans_dataframe(
        project_identifier="my-project",
        spans_dataframe=df,
    )
except SpanCreationError as error:
    print(error)
```

The dataframe must contain the span fields Phoenix needs, including span context, timing, status, and OpenInference attributes.

<Tip>
Phoenix rejects duplicate span IDs. If you are copying spans that already exist in Phoenix, regenerate span and trace IDs first:

```python
from phoenix.client.helpers.spans import uniquify_spans_dataframe

df = uniquify_spans_dataframe(df)
```
</Tip>

## Launch a local Phoenix instance with saved traces

Use `TraceDataset` when you want to open a local Phoenix instance from a dataframe or from a trace dataset you saved earlier.

```python
import phoenix as px

# Launch Phoenix from a dataframe of spans
px.launch_app(trace=px.TraceDataset(df))

# Launch Phoenix from a saved trace dataset
trace_dataset = px.TraceDataset.load(
    "f7733fda-6ad6-4427-a803-55ad2182b662",
    directory="/my_saved_traces/",
)
px.launch_app(trace=trace_dataset)
```

The local Phoenix instance runs only while your notebook or Python process is running.

## Save and reload a trace dataset

`TraceDataset.save` writes the trace dataset to disk and returns the dataset ID. Pass that ID to `TraceDataset.load` when you want to open it again.

```python
import phoenix as px

trace_dataset = px.TraceDataset(df)
dataset_id = trace_dataset.save(directory="/my_saved_traces/")

reloaded = px.TraceDataset.load(dataset_id, directory="/my_saved_traces/")
px.launch_app(trace=reloaded)
```
