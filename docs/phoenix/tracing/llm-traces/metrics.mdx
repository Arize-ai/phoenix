Project metrics show trends for traces in one Phoenix project. Use them to check latency, cost, token usage, errors, and annotation scores before you inspect individual traces.

To open project metrics, open a project and select the **Metrics** tab. You can also select **Dashboards** in the Phoenix sidebar, choose a project from the dropdown, and set the time range.

<Frame caption="Predefined metrics dashboard for a Phoenix project">
  ![Phoenix metrics dashboard showing traces over time and trace latency percentiles](https://storage.googleapis.com/arize-phoenix-assets/assets/images/phoenix-docs-images/ui/phoenix_dashboard.jpg)
</Frame>

Phoenix indexes traces for metrics after they are sent to a project. Each project dashboard includes these charts by default:

- **Traces** over time
- **Trace latency** percentiles
- **Cost** estimated in USD
- **Top models by cost**
- **Top models by tokens**
- **Token usage** by prompt and completion
- **Prompt token details** by input, cache, and audio parts
- **Completion token details** including output, reasoning, and audio parts
- **LLM spans** over time
- **LLM span errors** over time
- **Tool spans** over time
- **Tool span errors** over time
- **Span annotation scores**
- **Trace annotation scores**
- **Session annotation scores**

<Info>
  If you need custom alerting or business dashboards on top of trace data, see [Arize AX dashboards](https://arize.com/docs/ax/observe/dashboards).
</Info>
