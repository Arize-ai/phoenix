Sessions group traces that belong to the same conversation or user journey. Use sessions to review multi-turn behavior in order instead of opening each trace separately.

With sessions in Phoenix, you can:

* Review each turn in a conversation-style view

* Search sessions to find specific users or interactions

* Track token usage, cost, latency, and trace count across the conversation

* Attach and review session-level annotations

To create a session, tag related spans with the same session ID. Phoenix then shows those traces together so you can review the full interaction.

## What sessions show

The Sessions table shows the session ID, first input, last output, user ID, annotation summaries, start time, end time, p50 and p99 trace latency, total tokens, total cost, and total trace count. Open a session to review its traces and turns in order.
