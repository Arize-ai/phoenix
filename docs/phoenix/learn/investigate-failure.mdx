## Step 2: Define the behavior you want to label

An [**annotation**](/docs/phoenix/tracing/concepts-tracing/annotations-concepts) stores your assessment alongside the run. Start with one question that your notes support. For this example: did the recommendation respect the shopper's budget?

Use `budget_compliance` with these labels:

- **pass:** Recommended products are below the limit, or the agent explains that no match was found without recommending a more expensive product.
- **fail:** The agent recommends a product at or above the limit without the shopper agreeing to change it.

These are the review criteria for this exercise. A budget label doesn't assess age suitability or whether the products match the requested topic. Record those separately if your notes show a problem. Leave uncertain cases unlabeled and explain what needs checking.

<Accordion title="Ask PXI to define the criteria">
  > Draft pass/fail criteria for `budget_compliance`: recommended products must be below the shopper's limit unless they agree to change it. A no-match answer can pass without recommending a more expensive product. Assess other requirements separately and leave uncertain cases unlabeled.
</Accordion>

## Step 3: Configure the annotation in Phoenix

- Open **Settings → Annotations → New Configuration**. Name the annotation `budget_compliance` and choose **Categorical**.
- Add `pass` with score `1` and `fail` with score `0`. Keep **Maximize** selected, then choose **Create Annotation Config**.
- Return to **wonder-toys → Config** and enable it under **Annotation Configs**.

## Step 4: Label the request and explain the decision

- Return to the trace and select the top-level **Wonder Toys** span.
- Choose **Annotate this span**, select `budget_compliance`, and apply the label supported by your review.
- Add an explanation that cites the request and the relevant price.

For the recorded \$25 request, the label is `fail`: the final model received the \$27.99 price and still recommended the kit. Apply the same criteria to your other requests, including the ones that stayed within budget.

To find these labels again, open **wonder-toys → Spans** and enter:

```python
parent_span is None and annotations['budget_compliance'].label == 'fail'
```

The first condition selects top-level spans; the second selects the label you added. The notes and labels are attached to these spans, so use the **Spans** filter here.
