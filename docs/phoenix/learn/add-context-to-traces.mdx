In [Capture your first agent run](/docs/phoenix/learn/capture-first-run), you recorded the agent's model and tool calls. A model call might ask for a product search rather than give the shopper an answer. Looking at that call alone won't show you the complete reply.

Let's add a **Wonder Toys** agent span to record the shopper's request and complete answer together. It will sit above LangGraph and its existing `agent` and `tools` steps. This is [manual instrumentation](/docs/phoenix/tracing/how-to-tracing/setup-tracing/instrument#agents): we choose what the new span records.

## Before you start

Continue with your setup from the previous lesson:

- Keep Phoenix running at `http://localhost:6006`.
- Work in the same `no-observability/langchain-py` folder.
- Use the `_tracer_provider` you created in `backend/tracing.py`.

## Step 1: Add the agent span

For a function that returns an answer, Phoenix's [`@tracer.agent` decorator](/docs/phoenix/tracing/how-to-tracing/setup-tracing/instrument#agents) creates an **AGENT** span around the function call:

```python title="Pattern for an agent that returns an answer" wrap
tracer = _tracer_provider.get_tracer(__name__)

@tracer.agent(name="My agent")
def run_agent(request: str) -> str:
    return existing_agent(request)
```

Here, `existing_agent(request)` represents your app's existing call that returns the answer. The decorator records:

- **Input:** the function's argument, `request`.
- **Output:** the answer the function returns.
- **Child spans:** the instrumented model and tool calls made while the function runs.

Wonder Toys streams its answer in pieces using an async generator. For this streaming function, we'll use a **context manager**, a `with` block that keeps the span open until the reply finishes. We'll record the request when it starts and the collected answer when it ends.

    ```python title="stream_agent" highlight={15,16,17,18,44,48,54,55}
    async def stream_agent(messages: list[dict], user_id: str) -> AsyncIterator[str]:
        agent = get_agent()
        lc_messages = _lc_messages(messages, user_id)

        had_text_before = False
        in_tool_call = False

        question = next(
            (message.get("content", "") for message in reversed(messages)
             if message.get("role") == "user"),
            "",
        )
        response_parts = []

        with _tracer.start_as_current_span(
            "Wonder Toys", openinference_span_kind="agent"
        ) as root_span:
            root_span.set_input(question)
            async for event in agent.astream_events(
                {"messages": lc_messages},
                version="v2",
                config={"recursion_limit": 25},
            ):
                kind = event["event"]

                if kind == "on_chat_model_stream":
                    chunk = event["data"]["chunk"]
                    # Check for tool call chunks
                    if hasattr(chunk, "tool_call_chunks") and chunk.tool_call_chunks:
                        in_tool_call = True
                        continue

                    # Check for text content
                    text = ""
                    if isinstance(chunk.content, str):
                        text = chunk.content
                    elif isinstance(chunk.content, list):
                        for block in chunk.content:
                            if isinstance(block, dict) and block.get("type") == "text":
                                text += block.get("text", "")

                    if text:
                        if in_tool_call and had_text_before:
                            response_parts.append("\n\n")
                            yield f"data: {json.dumps({'text': chr(10) + chr(10)})}\n\n"
                        in_tool_call = False
                        had_text_before = True
                        response_parts.append(text)
                        yield f"data: {json.dumps({'text': text})}\n\n"

                elif kind == "on_tool_start":
                    in_tool_call = True

            root_span.set_output("".join(response_parts))
            root_span.set_status(StatusCode.OK)

        yield "data: [DONE]\n\n"
    ```

## Step 2: Send a request

With the edits in place, let's run the app and record a new request.

- **Restart the app.** Stop it in its terminal, then run this from `no-observability/langchain-py` to load your changes:

  ```bash
  UV_PYTHON=3.11 npm run dev
  ```

- **Send a request.** Once the app is ready, open `http://localhost:3000` and send:

  ```text wrap
  Find dinosaur toys for a 6-year-old under $25. Recommend at most 3 options.
  ```

Wait for the reply, then return to Phoenix to inspect this new request.

## Step 3: Inspect the result

Your new trace should now have a **Wonder Toys** span above **LangGraph**. In Phoenix:

- Open **wonder-toys → Traces** and select the latest **Wonder Toys** request.
- Select the **Wonder Toys** span and check that its kind is **AGENT**.
- Under **Info**, compare **Input** with the shopper's message and **Output** with the answer in the chat.
- Expand the tree to find the model and tool spans underneath it.
