## Before you start

Continue with the browser app from [Add an agent span](/docs/phoenix/learn/add-context-to-traces). Keep Phoenix running and work in the same `no-observability/langchain-py` folder.

The screenshots show one example conversation; your products and answers may be different.

## Step 1: Connect requests from the same conversation

Let's make Wonder Toys create a conversation ID automatically and send it with each message. You don't need to choose an ID or paste one into Phoenix.

- **First message:** the app creates an ID for the chat.
- **Follow-ups:** it reuses that ID so Phoenix groups the traces together.
- **New chat:** it creates a new ID for the next conversation.

In `backend/agent.py`, [`using_session`](/docs/phoenix/tracing/how-to-tracing/setup-tracing/setup-sessions#logging-conversations) goes around the agent span you added earlier:

```python title="Key change in backend/agent.py" highlight={1} wrap
with using_session(session_id), _tracer.start_as_current_span(
    "Wonder Toys", openinference_span_kind="agent"
) as root_span:
    root_span.set_input(question)
    # The existing streaming code continues here.
```

The app supplies `session_id` for the current chat. `using_session` records it as `session.id` on the spans. Choose one setup method below to connect the chat to this function.

## Step 2: Start a conversation and ask a follow-up

Open the app in your browser using the **Local** address shown in the terminal. Select the Wonder Toys logo to start a new chat, then send the original request again:

```text wrap
Find dinosaur toys for a 6-year-old under $25. Recommend at most 3 options.
```

This request starts your session. Earlier traces won't gain a session ID retroactively.

If the first answer didn't recommend a product, ask "What age and budget did I ask you to use?" instead. Check that reply against your original request for the rest of this exercise.

If it recommended a product, send these follow-ups in the same chat:

```text
Tell me more about the cheapest one you recommended. What is its product ID and age range?
```

Wait for the answer, then ask about the same toy without naming it:

```text
Would that same toy suit a 2-year-old? Use its listed age range.
```


## Step 3: Open the session in Phoenix

A **turn** is one shopper message and the agent's answer. Wonder Toys records each turn as a trace and groups them in the same session.

To open your conversation:

- Open **wonder-toys → Sessions** in Phoenix.
- Find your shopper's request in the **first input** column.
- Select that row's **session id**.

Under **Turns**, select each request on the left to read its message and answer on the right. Check that your original request and follow-ups appear together.

## Step 4: Compare the follow-up answers

Read the replies in order, using these checks for the toy questions:

- **Product:** Did the first follow-up identify the cheapest recommendation?
- **Age range:** Did the next reply refer to that same toy and use the age range given earlier?

In the example below, the final reply still names the Insect & Bug Collection and explains that its age range of 3 to 8 years excludes a 2-year-old.

## Step 5: Check the model's conversation history

To inspect the messages sent with the final follow-up:

- Select **Trace** beside the final turn.
- Select the first `ChatAnthropic` model call.
- Under **Info → Input**, expand the earlier message that the follow-up refers to.

<Frame caption="The earlier assistant reply appears in the model's input, including the toy's age range.">
  <img src="https://storage.googleapis.com/arize-phoenix-assets/assets/images/phoenix-academy/wonder-toys-session-history.png" alt="Phoenix session trace with ChatAnthropic selected and its Input section showing the earlier assistant reply naming the Insect and Bug Collection and its age range of 3 to 8 years" />

Use the message history to explain what happened:

- **Message missing:** The model didn't receive that earlier part of the conversation.
- **Message present:** Check whether the follow-up answer agrees with it.

Wonder Toys supplies this history, while the session ID groups the traces in Phoenix.

In this example:

> The model received the earlier reply naming the Insect & Bug Collection for ages 3 to 8. It then referred to the same toy and said it wasn't suitable for a 2-year-old.

Use your own trace to explain whether the follow-up answer matched the earlier messages in the model's input.

<Accordion title="Session IDs and user IDs">
  A `session.id` identifies one conversation, while a `user.id` identifies the person. If the same shopper starts a new chat, give it a new session ID and keep the same user ID.
</Accordion>
