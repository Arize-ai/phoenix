In this lesson, you'll learn to use **sessions** in Phoenix to review the traces from one conversation together. You'll practice with [Wonder Toys](https://github.com/Arize-ai/project-rosetta-stone), a shopping assistant agent, and check whether its follow-up answers match earlier messages.

## Before you start

Continue the chat from [Capture your first agent run](/docs/phoenix/learn/capture-first-run). Wonder Toys already sends the same `session.id` with the traces from that chat, so Phoenix groups them into a session.

For your own app, create an ID for each conversation and attach it as `session.id` to its spans. Reuse that ID for follow-ups. The [Set up sessions](/docs/phoenix/tracing/how-to-tracing/setup-tracing/setup-sessions) guide includes Python and TypeScript examples.

The screenshots show one example conversation; your products and answers may be different.

## Step 1: Ask a follow-up in the same chat

Send this message in Wonder Toys:

```text
Tell me more about the cheapest one you recommended. What is its product ID and age range?
```

Wait for the answer, then ask about the same toy without naming it:

```text
Would that same toy suit a 2-year-old? Use its listed age range.
```

If your first answer didn't recommend a product, ask "What age and budget did I ask you to use?" instead. Use that follow-up for the remaining steps.

## Step 2: Open the session in Phoenix

A **turn** is one shopper message and the agent's answer. Wonder Toys records each turn as a trace and groups them in the same session.

To open your conversation:

- Open **wonder-toys → Sessions** in Phoenix.
- Find your shopper's request in the **first input** column.
- Select that row's **session id**.

Under **Turns**, select each request on the left to read its message and answer on the right. Check that your original request and follow-ups appear together.

## Step 3: Compare the follow-up answers

Read the replies in order, using these checks for the toy questions:

- **Product:** Did the first follow-up identify the cheapest recommendation?
- **Age range:** Did the next reply refer to that same toy and use the age range given earlier?

In the example below, the final reply still names the Insect & Bug Collection and explains that its age range of 3 to 8 years excludes a 2-year-old.

The conversation shows whether the replies agree with each other. Next, check which earlier messages the model actually received.

## Step 4: Check the model's conversation history

To inspect the messages sent with the final follow-up:

- Select **Trace** beside the final turn.
- Select the first `ChatAnthropic` model call.
- Under **Info → Input**, expand the earlier message that the follow-up refers to.

<Frame caption="The earlier assistant reply appears in the model's input, including the toy's age range.">
  <img src="/docs/phoenix/learn/images/wonder-toys-session-history.png" alt="Phoenix session trace with ChatAnthropic selected and its Input section showing the earlier assistant reply naming the Insect and Bug Collection and its age range of 3 to 8 years" />
</Frame>

Use the message history to explain what happened:

- **Message missing:** The model didn't receive that earlier part of the conversation.
- **Message present:** Check whether the follow-up answer agrees with it.

Wonder Toys supplies this history, while the session ID groups the traces in Phoenix.

In this example:

> The model received the earlier reply naming the Insect & Bug Collection for ages 3 to 8. It then referred to the same toy and said it wasn't suitable for a 2-year-old.

Use your own trace to explain whether the follow-up answer matched the earlier messages in the model's input.

<Accordion title="Session IDs and user IDs">
  A `session.id` identifies one conversation, while a `user.id` identifies the person. If the same shopper starts a new chat, give it a new session ID and keep the same user ID.
</Accordion>
