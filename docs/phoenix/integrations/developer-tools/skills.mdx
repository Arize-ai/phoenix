A skill is a set of instructions your coding agent loads when a task matches it, such as debugging with the `px` CLI or writing an evaluator. Phoenix ships its skills in the [Phoenix repository](https://github.com/Arize-ai/phoenix/tree/main/.agents/skills), and the [Set Up Your Agent](/docs/phoenix/integrations/developer-tools/coding-agents) paths install them for you. This page is for installing or updating them on their own.

## Install

```bash
npx skills add Arize-ai/phoenix --skill phoenix-cli --skill phoenix-tracing
```

This writes each skill into the project's agent directory, such as `.claude/skills/` or `.cursor/skills/`, and lists what it installed and for which agents. Supported agents include Claude Code, Cursor, Windsurf, Codex, GitHub Copilot, Cline, OpenCode, Gemini CLI, and [20+ more](https://github.com/vercel-labs/skills#supported-agents). It needs no Phoenix instance and no traces.

Two other routes install the same skills: `px setup skills` from the [Phoenix CLI](/docs/phoenix/integrations/developer-tools/cli), and the [Claude Code plugin](/docs/phoenix/integrations/developer-tools/coding-agents#plugins), which registers `phoenix-cli`, `phoenix-evals`, and `phoenix-tracing`. The [Remote MCP Server](/docs/phoenix/integrations/mcp#how-it-works) also serves every skill through its `load_skill` tool, so a connected client can use them with nothing installed.

## Reference

### `skills add` options

| Option | Description |
|--------|-------------|
| `-g, --global` | Install to user directory instead of project |
| `-a, --agent <agents...>` | Target specific agents (for example, `claude-code`, `cursor`) |
| `-s, --skill <skills...>` | Install specific skills by name |
| `-l, --list` | List available skills without installing |
| `-y, --yes` | Skip confirmation prompts |

Examples:

```bash
# Install the CLI skill globally for all projects
npx skills add Arize-ai/phoenix --skill phoenix-cli -g

# Install CLI + tracing skills together
npx skills add Arize-ai/phoenix --skill phoenix-cli --skill phoenix-tracing

# Install for specific coding agents
npx skills add Arize-ai/phoenix --skill phoenix-cli -a claude-code -a cursor

# Non-interactive installation
npx skills add Arize-ai/phoenix --skill phoenix-cli -g -y
```

### Add your own skills

Point `PHOENIX_SKILLS_PATHS` on the Phoenix server at your own skill directories. The Remote MCP Server serves them to every connected client, and PXI lists them in its skill picker. See [Mounting your own skills](/docs/phoenix/integrations/mcp#mounting-your-own-skills).
