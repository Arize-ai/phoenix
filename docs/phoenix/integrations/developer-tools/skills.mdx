A skill is a set of instructions your coding agent loads when a task matches it, such as instrumenting an app or writing an evaluator. Phoenix ships five, in the [Phoenix repository](https://github.com/Arize-ai/phoenix/tree/main/skills).

## Get the skills

If you [connected your agent](/docs/phoenix/integrations/developer-tools/coding-agents) with a plugin or the MCP server, it already has the skills. There's nothing else to install.

| How your agent connects | Skills it gets | How they stay current |
| --- | --- | --- |
| [MCP server](/docs/phoenix/integrations/mcp) | Four: every skill except `phoenix-cli` | They ship with Phoenix, so they match the version of the Phoenix server you connect to. |
| [Claude Code, Codex, or Cursor plugin](/docs/phoenix/integrations/developer-tools/coding-agents#plugins) | All five, as files | They update when you update the plugin. |
| `npx skills add` | The ones you pick, as files | They're a copy. Rerun the command to update them. |

The MCP server lists each skill's name and a short summary in the instructions it sends when your agent connects. The agent loads a skill's full instructions with the `load_skill` tool only when a task needs them. Your own [custom skills](#add-your-own-skills) reach agents the same way.

`phoenix-cli` isn't served over MCP because it runs `px` commands in a shell. To use it, install it as a file.

## Install skills as files

To install skills into your agent's skills directory, such as `.claude/skills/`, run:

```bash
npx skills add Arize-ai/phoenix
```

The command asks which skills and agents to install for. To install one skill, add `--skill`, for example `--skill phoenix-cli`.

Install skills as files when your agent has no MCP support, or when you use the [Phoenix CLI](/docs/phoenix/integrations/developer-tools/cli) without a plugin and want the `phoenix-cli` skill. An agent with both files and the MCP server sees four of the skills from both sources. That's expected. If the two copies differ, the MCP copy is the one that matches your Phoenix server.

## Add your own skills

Set `PHOENIX_SKILLS_PATHS` on the Phoenix server to one or more directories of your own [Agent Skills](https://agentskills.io/specification); the MCP server serves them alongside the built-in ones:

```bash
PHOENIX_SKILLS_PATHS=/opt/skills/team-analysis,/srv/agents/skills
```

Each skill is a directory named after the `name` in its `SKILL.md` frontmatter, which also needs a `description`.
