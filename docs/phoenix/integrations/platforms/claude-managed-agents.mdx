[Claude Managed Agents](https://platform.claude.com/docs/en/managed-agents/overview) runs the agent loop on Anthropic's servers and executes tools in an Anthropic-hosted sandbox. Phoenix can ingest the OpenTelemetry GenAI spans that Claude Platform exports and convert them to OpenInference so you can inspect turns, model requests, tool calls, and token usage.
