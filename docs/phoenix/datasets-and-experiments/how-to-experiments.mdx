## Running Experiments

Phoenix supports two workflows for experiments: a UI-driven flow in the Playground and a programmatic SDK flow.

<CardGroup cols={2}>
  <Card img="https://storage.googleapis.com/arize-phoenix-assets/assets/images/docs-cards/topics/experiment.avif" title="Run Experiments in the UI" href="/docs/phoenix/datasets-and-experiments/how-to-experiments/running-experiments#run-experiments-in-the-ui">
    Configure prompts and evaluators in the Playground and compare results.
  </Card>
  <Card img="https://storage.googleapis.com/arize-phoenix-assets/assets/images/docs-cards/topics/experiment.avif" title="Run Experiments with the SDK" href="/docs/phoenix/datasets-and-experiments/how-to-experiments/running-experiments#run-experiments-with-the-sdk">
    Run experiments programmatically with tasks and evaluators in code.
  </Card>
  <Card img="https://storage.googleapis.com/arize-phoenix-assets/assets/images/docs-cards/topics/experiment.avif" title="Run Experiments in the Background" href="/docs/phoenix/datasets-and-experiments/how-to-experiments/running-experiments-in-background">
    Start experiments from the Playground that keep running after you close the browser, and stop or resume them anytime.
  </Card>
</CardGroup>
