**Available in arize-phoenix-client 3.4.0+, with trajectory traces in 3.5.0+**

Phoenix now ships a job plugin for [Harbor](https://harborframework.com/). Select it on a Harbor run
and the job lands in Phoenix as a dataset, one experiment per resolved agent configuration, a run per
trial, and every verifier reward as a named evaluation. No tracing code goes inside the sandbox.

## Trajectories Become Traces

<Frame caption="A Harbor trial's trajectory as a Phoenix trace, opened from its experiment run: the `harbor.trial` root, the agent beneath it, and an LLM and a tool span for each iteration.">
  <img src="https://storage.googleapis.com/arize-phoenix-assets/assets/images/harbor/harbor-trial-trace.png" alt="Phoenix experiment run trace for a Harbor trial, with the harbor.trial root span above the codex agent span and its iteration, openai/gpt-5.6 LLM, and exec_command tool spans, beside the selected tool span's input and output" />
</Frame>

- **`trace_mode="atif"` is the default.** The plugin reads the saved trajectory after the final trial
  attempt and converts it into one trace and one session, with AGENT, LLM, and TOOL spans under a
  `harbor.trial` root. A multi-step trial adds a span for each attempted step, and
  context-management operations appear as `compaction` spans.
- **Tracing never changes a score.** If the agent saves no valid trajectory, the plugin logs a
  warning and records the run and its evaluations without a trace. Pass `trace_mode=null` on the
  Harbor command line to turn tracing off entirely.
- **The sandbox stays offline.** The plugin converts trajectories after the trial, so the agent's
  environment needs no Phoenix endpoint and no Phoenix credentials.

## Run a Job with the Plugin

Install Harbor and the plugin into the same Python environment:

```bash
uv pip install "arize-phoenix-client[harbor]"
```

The plugin registers under the name `arize-phoenix`, so a Harbor run picks it up directly:

```bash
harbor run \
  -d terminal-bench/terminal-bench-2 \
  -a terminus-2 \
  -m openai/gpt-5-mini \
  --plugin arize-phoenix \
  --yes
```

Configure it in Python when you want the dataset name or the naming template under version control:

```python
from phoenix.client.harbor import PhoenixJobPlugin

plugin = PhoenixJobPlugin(
    dataset="terminal-bench",
    experiment_name_template="{job.name} · {agent.name} · {agent.model}",
    trace_mode="atif",
)
```

- **Experiment names follow a template.** `experiment_name_template` accepts fields like
  `{job.name}`, `{agent.name}`, `{agent.model}`, and `{agent.short_digest}`, and
- **Resuming the same Harbor job** reuses its experiments without duplicating recorded runs.
- **Resuming is idempotent**, so a re-run adds to the same experiment instead of duplicating it.
