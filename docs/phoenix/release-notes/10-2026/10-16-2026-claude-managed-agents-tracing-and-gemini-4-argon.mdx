# Tracing for Claude Managed Agents and Atomic Agents

October 15 to 16, 2026

**New integration guides; no Phoenix upgrade required**

New integration guides show how to send traces from two more agent stacks to Phoenix.

- **Claude Managed Agents.** Add an **Arize Phoenix** destination in the Claude Console to export agent turns, model requests, and sandbox tool calls with no code changes. Phoenix converts the OpenTelemetry GenAI spans to OpenInference when they arrive. Trace the Claude SDK from your application too, and each session nests inside your own trace.
- **Atomic Agents.** Atomic Agents 2.11.0+ ships its own OpenInference instrumentor, which emits an `AGENT` span per agent run and a `TOOL` span per tool call. `register(auto_instrument=True)` picks it up automatically.

```python
from phoenix.otel import register

tracer_provider = register(
    project_name="atomic-agents-app",
    auto_instrument=True,
)
```

# Export Phoenix Server Logs over OTLP

October 16, 2026

**Available in arize-phoenix 20.23.0+**

Send the Phoenix server's own logs to an OpenTelemetry collector, next to the server traces you may already export. Set `PHOENIX_SERVER_INSTRUMENTATION_OTLP_LOG_COLLECTOR_HTTP_ENDPOINT` or `PHOENIX_SERVER_INSTRUMENTATION_OTLP_LOG_COLLECTOR_GRPC_ENDPOINT` to turn it on.

- **Logs carry trace and span IDs**, so your observability backend can link each log line to the server request that produced it.
- **Endpoints follow the trace collector variables.** HTTP endpoints get `/v1/logs` appended. gRPC endpoints without a scheme connect over TLS, so prefix a plaintext collector with `http://`.

# Additional Improvements

October 14 to 16, 2026

**Available in arize-phoenix 20.21.4–20.23.0**

- **OAuth2 sign-in completes on the first try** when an identity provider login happens in the middle of an authorization flow, because Phoenix keeps its `SameSite=Strict` session cookies.
- **Bedrock tool results reach the model as text** in the playground, so tool output that is not valid JSON no longer fails the request.
- **Pressing Escape keeps prompt and dataset labels** instead of removing every label from the item.
- **Dataset labels no longer need a description** when you create them.
- **Sorting projects by last updated** shows the newest projects first on the first click.
