## Integration Types

Phoenix offers several types of integrations to support your AI development workflow:

<CardGroup cols={2}>
  <Card img="https://storage.googleapis.com/arize-phoenix-assets/assets/images/docs-cards/topics/cli.avif" title="Developer Tools" href="#developer-tools">
    Integrate Phoenix with AI coding assistants like Claude Code and Cursor for debugging and analysis.
  </Card>
  <Card img="https://storage.googleapis.com/arize-phoenix-assets/assets/images/docs-cards/topics/trace.avif" title="Tracing Integrations" href="#tracing-integrations">
    Automatically capture traces from your AI applications built with popular frameworks and LLM providers.
  </Card>
  <Card img="https://storage.googleapis.com/arize-phoenix-assets/assets/images/docs-cards/topics/judge.avif" title="Eval Model Integrations" href="#eval-model-integrations">
    Use any LLM provider to power Phoenix's evaluation capabilities for scoring and classifying your traces.
  </Card>
  <Card img="https://storage.googleapis.com/arize-phoenix-assets/assets/images/docs-cards/topics/eval.avif" title="Evaluation Integrations" href="#evaluation-integrations">

  </Card>
  <Card img="https://storage.googleapis.com/arize-phoenix-assets/assets/images/docs-cards/topics/pipeline.avif" title="Span Processors" href="#span-processors">

  </Card>
  <Card img="https://storage.googleapis.com/arize-phoenix-assets/assets/images/docs-cards/topics/sandbox.avif" title="Sandboxes" href="#sandboxes">

  </Card>
</CardGroup>
