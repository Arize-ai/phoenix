## Start from a project

Projects are the main container for trace data. Open a project to review the spans, traces, and sessions collected from one application or environment.

Use the table views to move between different levels of detail:

- **Spans** show individual operations, such as LLM calls, retrieval steps, tool calls, and custom spans.
- **Traces** show full request paths from the root span through child spans.
- **Sessions** group related traces from the same conversation or user journey.

Open a row to inspect details such as inputs, outputs, attributes, timing, errors, annotations, and tool call data.

## Narrow what you see

Use the project time range and table filter bars to focus the view. Filter expressions can target span fields, trace rollups, session aggregates, attributes, metadata, and annotations.

## Review metrics over time

Use dashboards and metrics when you need a project-level view before reading individual traces. The dashboard includes charts for trace volume, latency, estimated cost, token usage, LLM and tool span errors, and annotation scores.
