## Export and query spans

Use the Phoenix client when you want to analyze spans in code, build evaluation datasets, or include annotations such as human feedback and evaluator results.

Phoenix gives you two main span export paths:

| Method | Use when |
|---|---|
| `get_spans_dataframe` | You want all matching spans as a pandas dataframe. |
| `SpanQuery` | You want Phoenix to filter, select, explode, or concatenate span attributes before returning a dataframe. |

### Connect to Phoenix

<ConnectToPhoenixPython />

```python
from phoenix.client import Client

client = Client()
```

### Export spans to a dataframe

Use `get_spans_dataframe` when you want to filter, join, or evaluate spans locally with pandas.

```python
from phoenix.client import Client

client = Client()

# Download spans from the default project
spans = client.spans.get_spans_dataframe()

# Download spans from a specific project
spans = client.spans.get_spans_dataframe(project_identifier="my-project")
```

Limit exports by time when you only need a recent window.

```python
from datetime import datetime, timedelta
from phoenix.client import Client

client = Client()

start = datetime.now() - timedelta(days=7)
end = datetime.now()

spans = client.spans.get_spans_dataframe(start_time=start, end_time=end)
```

### Query spans

Use `SpanQuery` when you want Phoenix to filter or reshape spans before returning a dataframe.

<Check>
The `.where()` filter expression uses the same language as the Phoenix filter bar. See [Filter trace data](/docs/phoenix/tracing/how-to-tracing/filter-expressions) for the full reference.
</Check>

<Info>
By default, result dataframes are indexed by `span_id`. If you use `.explode()`, Phoenix adds the exploded list index to the dataframe index. For `retrieval.documents`, that added index is named `document_position`.
</Info>

This query returns retriever spans with their input value.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

query = (
    SpanQuery()
    .where("span_kind == 'RETRIEVER'")
    .select("input.value")
    .rename(**{"input.value": "input"})
)

retriever_spans = client.spans.get_spans_dataframe(query=query)
```

Use the same pattern to combine filters, selected fields, and output column names.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

query = (
    SpanQuery()
    .where("span_kind == 'RETRIEVER' and 'programming' in input.value")
    .select("input.value", "output.value")
    .rename(**{"input.value": "input", "output.value": "output"})
)

matching_spans = client.spans.get_spans_dataframe(query=query)
```

### Extract retrieved documents

Use `.explode()` when a span attribute contains a list. The example below returns one row per retrieved document.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

query = (
    SpanQuery()
    .where("span_kind == 'RETRIEVER'")
    .select("input.value")
    .rename(**{"input.value": "input"})
    .explode(
        "retrieval.documents",
        context="document.content",
        score="document.score",
    )
)

retrieved_documents = client.spans.get_spans_dataframe(query=query)
```

### Join spans for evaluation

Run separate queries when evaluation data lives on different spans, then join the dataframes with pandas.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

root_query = (
    SpanQuery()
    .where("parent_id is None")
    .select("input.value", "output.value")
    .rename(**{"input.value": "input", "output.value": "output"})
)

retriever_query = (
    SpanQuery()
    .where("span_kind == 'RETRIEVER'")
    .concat("retrieval.documents", context="document.content")
    .with_index("parent_id")
)

root_spans = client.spans.get_spans_dataframe(query=root_query)
retriever_context = client.spans.get_spans_dataframe(query=retriever_query)

evaluation_data = root_spans.join(retriever_context, how="inner")
```

Use the resulting dataframe with [pre-built evaluations](/docs/phoenix/evaluation/pre-built-metrics) such as correctness or retrieval relevance.

### SpanQuery patterns

Use these methods together when you need more control over the dataframe shape.

| Method | What it does |
|---|---|
| `.where("span_kind == 'LLM'")` | Filters spans before data is returned. |
| `.select("input.value")` | Selects span attributes. |
| `.rename(**{"input.value": "input"})` | Renames output columns. |
| `.explode("retrieval.documents", context="document.content")` | Returns one row per item in a list attribute. |
| `.concat("retrieval.documents", context="document.content")` | Keeps one row per span and joins list values into one column. |
| `.with_index("parent_id")` | Sets the dataframe index so child spans can be joined to parent spans. |

`project_identifier` can be a project name or ID. If you omit it, Phoenix uses the default project or the project set by `PHOENIX_PROJECT`.

### Export annotated spans

Use annotation filters when you want spans that already have human feedback or evaluator results. You can filter by annotation presence, score, or label.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

query = SpanQuery().where("annotations['correctness']")
# query = SpanQuery().where("annotations['correctness'].score == 1")
# query = SpanQuery().where("annotations['correctness'].label == 'correct'")

spans = client.spans.get_spans_dataframe(
    query=query,
    project_identifier="default",
)
```

To filter by trace-level annotations, use `trace_annotations`.

```python
from phoenix.client import Client
from phoenix.client.types.spans import SpanQuery

client = Client()

query = SpanQuery().where("trace_annotations['quality'].score >= 0.5")

spans = client.spans.get_spans_dataframe(
    query=query,
    project_identifier="default",
)
```

Pull the matching span annotations and join them with the span dataframe.

```python
annotations = client.spans.get_span_annotations_dataframe(
    spans_dataframe=spans,
    project_identifier="default",
)

annotated_spans = annotations.join(spans, how="left")
```

You can also fetch annotations by span ID.

```python
annotations = client.spans.get_span_annotations_dataframe(
    span_ids=list(spans.index),
    project_identifier="default",
)
```

## Retrieve traces with the CLI

Use the Phoenix CLI when you want trace data in your terminal, a file, or another tool. The CLI is useful for debugging, JSON export, shell pipelines, CI checks, and coding-agent handoff.

### Install

```bash
npm install -g @arizeai/phoenix-cli
```

Or run it without installing:

```bash
npx @arizeai/phoenix-cli
```

### Configure

Point the CLI at Phoenix and choose a project.

```bash
export PHOENIX_ENDPOINT=http://localhost:6006
export PHOENIX_PROJECT=my-project
```

For authenticated Phoenix instances, also set an API key.

```bash
export PHOENIX_API_KEY=your-api-key
```

### Command reference

The CLI uses the shape `px <resource> <action> [arguments] [options]`.

| Command | Fetches | Output |
|---|---|---|
| `px project list` | Phoenix projects | Terminal |
| `px trace list [directory]` | Recent traces | Terminal, or one JSON file per trace when you pass a directory |
| `px trace get <trace-id>` | One trace | Terminal, or a file with `--file` |
| `px span list` | Recent or filtered spans | Terminal, or a JSON file when you pass a file path |
| `px session list` | Sessions in a project | Terminal |
| `px session get <session-id>` | One session and its traces | Terminal |

Useful options:

| Option | Use when |
|---|---|
| `--limit <number>` | Limit how many traces, spans, or sessions are returned. |
| `--last-n-minutes <number>` | Fetch recent traces or spans from a rolling time window. |
| `--since <timestamp>` and `--until <timestamp>` | Fetch traces or spans from an ISO 8601 time range. |
| `--project <name-or-id>` | Override `PHOENIX_PROJECT` for one command. |
| `--format pretty \| json \| raw` | Choose terminal view, formatted JSON, or compact JSON. |
| `--no-progress` | Remove progress output when piping to `jq` or another tool. |
| `--include-annotations` | Include reviewer or evaluator annotations. |
| `--include-notes` | Include notes added in Phoenix or with `px trace add-note`, `px span add-note`, or `px session add-note`. |

### List recent traces

Use `px trace list` when you want the latest traces from a project.

```bash
px trace list --limit 10
```

Save traces as JSON files by passing a directory.

```bash
px trace list ./my-traces --limit 50
```

Filter by time when you only need recent traffic.

```bash
px trace list --last-n-minutes 30 --limit 20
px trace list --since 2026-01-13T10:00:00Z --until 2026-01-14T10:00:00Z
```

### Fetch one trace

Use `px trace get` when you know the trace ID.

```bash
px trace get abc123def456
```

Save the trace to a file or pipe compact JSON to `jq`.

```bash
px trace get abc123def456 --file trace.json
px trace get abc123def456 --format raw | jq '.spans[] | select(.span_kind == "LLM")'
```

Include annotations when you need reviewer or evaluator results.

```bash
px trace get abc123def456 --include-annotations --format json
```

Include notes separately when you want reviewer notes.

```bash
px trace get abc123def456 --include-notes --format json
```

### Fetch spans

Use `px span list` when you want to inspect the spans inside traces without fetching full trace trees.

```bash
px span list --limit 20
px span list --span-kind LLM --limit 10
px span list --status-code ERROR --limit 20
px span list --trace-id abc123def456 --format raw --no-progress | jq .
```

Filter by attributes when you know the field you need.

```bash
px span list --attribute llm.model_name:gpt-4 --limit 10
px span list --attribute session.id:my-chat-session-001 --limit 20
```

### Fetch sessions

Sessions group related traces, such as turns in a conversation.

```bash
px session list --limit 10
px session get my-chat-session-001
```

Pipe raw session output when you want to script against it.

```bash
px session list --format raw --no-progress | jq '.[].session_id'
px session get my-chat-session-001 --format raw | jq '.session.traces[].trace_id'
```

Include session annotations or notes when you need reviewer context.

```bash
px session get my-chat-session-001 --include-annotations --format json
px session get my-chat-session-001 --include-notes --format json
```

### Output fields

`json` and `raw` trace output include the trace summary plus its spans.

| Field | Meaning |
|---|---|
| `traceId` | Trace identifier. |
| `status` | Trace status, such as `OK` or `ERROR`. |
| `duration` | Trace duration in milliseconds. |
| `rootSpan` | The top-level span for the trace. |
| `spans[]` | The full span list, including `span_kind`, timing, status, parent ID, and attributes. |

Common OpenInference attributes appear under `attributes`, including `input.value`, `output.value`, `llm.model_name`, token counts, tool fields, retrieval documents, and exception details.

### Use with coding agents

Ask an agent with terminal access to run `px` directly:

```text
Use px to fetch the last 3 traces from my Phoenix project and summarize the failures.
```

For a persistent agent connection, use [MCP](/docs/phoenix/integrations/remote-mcp) or install Phoenix skills with `px setup skills`. See [Coding agents](/docs/phoenix/integrations/developer-tools/coding-agents).

### Useful pipelines

Find failed traces:

```bash
px trace list --limit 100 --format raw --no-progress | \
  jq '[.[] | select(.status == "ERROR")]'
```

Review the slowest traces:

```bash
px trace list --limit 20 --format raw --no-progress | \
  jq 'sort_by(-.duration) | .[0:5]'
```

Extract LLM token counts:

```bash
px trace list --limit 50 --format raw --no-progress | \
  jq '[.[].spans[] | select(.span_kind == "LLM") | {name, model: .attributes["llm.model_name"], tokens: .attributes["llm.token_count.total"]}]'
```

### Troubleshooting

If Phoenix cannot be found, set the endpoint or pass it as a flag.

```bash
export PHOENIX_ENDPOINT=http://localhost:6006
px trace list --endpoint http://localhost:6006 --limit 10
```

If the project cannot be resolved, set `PHOENIX_PROJECT` or pass `--project`.

```bash
export PHOENIX_PROJECT=my-project
px trace list --project my-project --limit 10
```

List projects when you need the exact name.

```bash
px project list
```
