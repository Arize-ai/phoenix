**Span Replay** lets you go back into a multi-step LLM chain and replay one step, to see if a change gives a better outcome. You can load any LLM span that Phoenix stores into the Prompt Playground and replay it there. Replay helps you debug and improve the performance of your LLM system: you can compare outputs from LLM providers, change model parameters, change prompt text, and more.

Phoenix automatically instruments the chat completions that the Playground generates. The recorded spans are immediately available for replay in the Playground.

For a walkthrough that replays a span and edits its prompt, see [Identify and edit prompts](/docs/phoenix/prompt-engineering/tutorial/identify-and-edit-prompts).
