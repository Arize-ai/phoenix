Prompt management lets you create, store, and change the prompts that your application sends to LLMs. When you manage prompts systematically, you can reuse them, keep them consistent, and test variations across different models and inputs.

Prompt management has these key benefits:

* **Reusability**: Store prompts and load them for different use cases.

* **Versioning**: Track changes over time, so that your application uses the version with the best performance.

* **Collaboration**: Share prompts with other people to keep them consistent and to make iteration easier.

To create your first prompt, see [Create a prompt](/docs/phoenix/prompt-engineering/how-to-prompts/create-a-prompt).
