title: "Migrating to Arize AX"
description: Migrate Phoenix data to Arize AX with the supported migration skill
---

The supported way to migrate Phoenix data to Arize AX is the [Phoenix migration guide in the Arize AX documentation](https://arize.com/docs/ax/cookbooks/migrate/migrate-from-phoenix#migrate-existing-phoenix-data).

The guide uses the [Arize Phoenix migration skill](https://github.com/Arize-ai/arize-skills/tree/main/skills/arize-phoenix-migration) to help a coding agent inventory Phoenix data, migrate supported traces, datasets, and experiment data, and verify the results in AX. It also documents prerequisites, supported fields, and limitations.
