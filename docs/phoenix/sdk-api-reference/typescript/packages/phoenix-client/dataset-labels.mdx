Dataset labels are reusable, global resources for organizing datasets. The `@arizeai/phoenix-client/datasetLabels` entrypoint provides typed helpers to list, get, create, update, and delete those resources.

<Warning>
Dataset label **resources** and dataset label **assignments** are different. The helpers on this page manage the global resource itself; they do not attach a label to a dataset. An assignment links an existing resource to one dataset. Removing an assignment preserves the label resource, while deleting the resource removes it from every dataset where it is assigned.
</Warning>

## Create And Read Labels

Names are unique across Phoenix. Creating a label whose name already exists rejects with an `HttpError` whose `status` is `409`.

```ts
import { HttpError } from "@arizeai/phoenix-client";
import {
  createDatasetLabel,
  getDatasetLabel,
} from "@arizeai/phoenix-client/datasetLabels";

try {
  const created = await createDatasetLabel({
    name: "golden",
    color: "#00cc88",
    description: "Curated reference datasets",
  });

  const label = await getDatasetLabel({ labelId: created.id });
  console.log(label.name);
} catch (error) {
  if (error instanceof HttpError && error.status === 409) {
    console.error("That dataset label name already exists.");
  }
}
```

## List Labels With Cursor Pagination

`listDatasetLabels()` returns one page at a time. Pass `nextCursor` from one result as `cursor` on the next request.

```ts
import { listDatasetLabels } from "@arizeai/phoenix-client/datasetLabels";

let cursor: string | null | undefined;

do {
  const page = await listDatasetLabels({ cursor, limit: 100 });

  for (const label of page.datasetLabels) {
    console.log(label.id, label.name);
  }

  cursor = page.nextCursor;
} while (cursor != null);
```

## Partially Update A Label

Only fields you supply are changed. Omitted fields stay as they are, and `description: null` clears the description.

```ts
import { updateDatasetLabel } from "@arizeai/phoenix-client/datasetLabels";

const updated = await updateDatasetLabel({
  labelId: "RGF0YXNldExhYmVsOjE=",
  description: null,
});
```

## Delete A Label Resource

Deleting a global label also removes every assignment of that label. To detach a label from only one dataset, use the assignment route instead of `deleteDatasetLabel()`.

```ts
import { deleteDatasetLabel } from "@arizeai/phoenix-client/datasetLabels";

await deleteDatasetLabel({ labelId: "RGF0YXNldExhYmVsOjE=" });
```

## Resource Helpers

| Helper | Purpose |
|--------|---------|
| `listDatasetLabels` | Return one cursor-paginated page of global resources |
| `getDatasetLabel` | Read one global resource by label ID |
| `createDatasetLabel` | Create a reusable resource with a unique name |
| `updateDatasetLabel` | Partially update a resource's name, color, or description |
| `deleteDatasetLabel` | Delete a resource and all of its assignments |

Dataset assignments use the separate `/v1/datasets/{dataset_identifier}/labels` routes. They control which existing labels are applied to a dataset and do not create, update, or delete the global resources documented here.
