Arize Phoenix on Arizen avoimen lähdekoodin AI-havaittavuusalusta, joka on suunniteltu kokeiluun, arviointiin ja vianetsintään. Hallinnoituja tuotantotyönkulkuja varten Arize tarjoaa myös [Arize AX](https://arize.com/products/ax/):n. Phoenix tarjoaa:

- [**_Tracing_**](https://arize.com/docs/phoenix/tracing/llm-traces) - Jäljitä LLM-sovelluksesi suoritusta OpenTelemetry-pohjaisella instrumentoinnilla.
- [**_Arviointi_**](https://arize.com/docs/phoenix/evaluation/llm-evals) - Hyödynnä LLM:iä sovelluksesi suorituskyvyn mittaamiseen vastaus- ja hakuevaleilla.
- [**_Datasetit_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets) - Luo versioituja esimerkkidatasettejä kokeiluun, arviointiin ja hienosäätöön.
- [**_Kokeet_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets#experiments) - Seuraa ja arvioi promptteihin, LLM:iin ja hakuun tehtyjä muutoksia.
- [**_Playground_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts)- Optimoi promptteja, vertaile malleja, säädä parametreja ja toista jäljitettyjä LLM-kutsuja.
- [**_Promptien hallinta_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts/prompt-management)- Hallitse ja testaa promptimuutoksia järjestelmällisesti versionhallinnan, tagien ja kokeilun avulla.
- [**_PXI (Phoenix Intelligence)_**](https://arize.com/docs/phoenix/pxi) - Phoenixiin sisäänrakennettu AI-insinööriagentti tracejen virheenkorjaukseen, promptien iterointiin ja tuotteessa navigointiin.
- [**_Etä-MCP-palvelin_**](https://arize.com/docs/phoenix/integrations/remote-mcp) - Yhdistä Claude Code, Cursor ja muut MCP-asiakkaat suoraan Phoenix-instanssisi `/mcp`-päätepisteeseen ja tee kyselyitä traceihin, datasetteihin, kokeisiin ja muuhun.

Phoenix on toimittaja- ja kieliriippumaton, ja se tukee valmiiksi suosittuja kehyksiä ([OpenAI Agents SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai-agents-sdk), [Claude Agent SDK](https://arize.com/docs/phoenix/integrations/python/claude-agent-sdk), [LangGraph](https://arize.com/docs/phoenix/tracing/integrations-tracing/langchain), [Vercel AI SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/vercel-ai-sdk), [Mastra](https://arize.com/docs/phoenix/integrations/typescript/mastra), [CrewAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/crewai), [LlamaIndex](https://arize.com/docs/phoenix/tracing/integrations-tracing/llamaindex), [DSPy](https://arize.com/docs/phoenix/tracing/integrations-tracing/dspy)) ja LLM-palveluntarjoajia ([OpenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai), [Anthropic](https://arize.com/docs/phoenix/tracing/integrations-tracing/anthropic), [Google GenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/google-genai), [Google ADK](https://arize.com/docs/phoenix/integrations/llm-providers/google-gen-ai/google-adk-tracing), [AWS Bedrock](https://arize.com/docs/phoenix/tracing/integrations-tracing/bedrock), [OpenRouter](https://arize.com/docs/phoenix/integrations/python/openrouter), [LiteLLM](https://arize.com/docs/phoenix/tracing/integrations-tracing/litellm) ja muita). Lisätietoja automaattisesta instrumentoinnista löydät [OpenInference](https://github.com/Arize-ai/openinference)-projektista.

Phoenix toimii käytännössä missä tahansa: paikallisella koneellasi, konttipohjaisessa käyttöönotossa tai pilvessä. Katso [Ympäristöt](https://arize.com/docs/phoenix/environments), jossa kukin vaihtoehto käydään läpi, tai siirry suoraan [Tracingin pikaoppaaseen](https://arize.com/docs/phoenix/get-started/get-started-tracing).

> [!NOTE]
> Phoenix on avointa lähdekoodia ja itse ylläpidettävä. Hallinnoituna alustana Arize tarjoaa [Arize AX](https://arize.com/products/ax/):n — sama OpenTelemetry/OpenInference-instrumentointi toimii molempien kanssa. Katso [täydellinen vertailu](https://arize.com/docs/phoenix/resources/frequently-asked-questions/what-is-the-difference-between-phoenix-and-arize).

## Paikallinen ajaminen

Asenna Phoenix `pip`:n tai `conda`:n avulla, niin käytössäsi on täysin toimiva Phoenix. Kaikki asennus- ja ylläpitovaihtoehdot löydät [asennusoppaasta](https://arize.com/docs/phoenix).

```shell
pip install arize-phoenix
phoenix serve
```

Tai aja se ilman asennusta [`uvx`](https://docs.astral.sh/uv/):n avulla:

```shell
uvx arize-phoenix serve
```

## Sovelluksesi jäljittäminen

Nopein tapa lähettää traceja on antaa [koodausagenttisi](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) (Claude Code, Codex, Cursor ja muut) instrumentoida sovelluksesi. Aja projektihakemistossasi:

```shell
npx @arizeai/phoenix-cli setup
# tai, jos Phoenix on asennettu: px setup
```

Asennus tunnistaa käyttämäsi kehyksen ja LLM-palveluntarjoajan, asentaa oikean [OpenInference](https://github.com/Arize-ai/openinference)-instrumentoinnin ja kytkee tracejen viennin. Haluatko mieluummin määrittää sen koodissa? Katso [tracing-dokumentaatio](https://arize.com/docs/phoenix/tracing/llm-traces).

## Ihmisille ja koodausagenteille

Phoenix on suunniteltu sekä ihmisten että AI-koodausagenttien käytettäväksi. Kolme rajapintaa antaa agenttien (Claude Code, Codex, Cursor ja muut) työskennellä tracejesi, datasettiesi ja kokeidesi kanssa:

- **[CLI](https://arize.com/docs/phoenix/sdk-api-reference/typescript/arizeai-phoenix-cli)** — `npx @arizeai/phoenix-cli` hakee traceja, datasettejä ja kokeita sekä instrumentoi sovelluksesi (`setup`), joten agentti voi hakea kontekstia ja toimia sen pohjalta suoraan päätteestä.
- **[Skillit](https://docs.anthropic.com/en/docs/claude-code/skills)** — [`.agents/skills/`](../../.agents/skills/) sisältää työnkulkuja, jotka opettavat agenteille virheenkorjauksen, arvioinnin ja tracingin Phoenixin avulla.
- **[Etä-MCP-palvelin](https://arize.com/docs/phoenix/integrations/remote-mcp)** — yhdistä mikä tahansa MCP-asiakas instanssisi `/mcp`-päätepisteeseen ja tee kyselyitä suoraan Phoenixiin.

Asennus- ja käyttöohjeet löydät [koodausagenttien dokumentaatiosta](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents).

| Skill                                              | Kuvaus                                                                                                                |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [phoenix-cli](../../.agents/skills/phoenix-cli/)         | LLM-sovellusten virheenkorjaus Phoenix CLI:llä — tracejen haku, virheiden analysointi, kokeiden tarkastelu ja GraphQL API -kyselyt |
| [phoenix-evals](../../.agents/skills/phoenix-evals/)     | Arvioijien rakentaminen ja ajaminen AI/LLM-sovelluksille Phoenixin avulla                                                             |
| [phoenix-tracing](../../.agents/skills/phoenix-tracing/) | OpenInferencen semanttiset konventiot ja instrumentointi LLM-sovellusten tracingiin                                        |

### Telemetria

Oletuksena Phoenix kerää perustason verkkoanalytiikkaa (esim. sivujen katselukerrat, käyttöliittymän vuorovaikutukset) auttaakseen meitä ymmärtämään, miten Phoenixia käytetään, ja parantamaan tuotetta. **Trace-dataasi, arviointituloksiasi tai mitään arkaluonteisia tietoja ei kerätä koskaan.**

Voit poistaa telemetrian käytöstä asettamalla ympäristömuuttujan: `PHOENIX_TELEMETRY_ENABLED=false`
