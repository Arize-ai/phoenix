Arize Phoenix là nền tảng quan sát AI mã nguồn mở của Arize, được thiết kế cho thử nghiệm, đánh giá và khắc phục sự cố. Đối với các quy trình vận hành production được quản lý, Arize còn cung cấp [Arize AX](https://arize.com/products/ax/). Phoenix cung cấp:

- [**_Tracing_**](https://arize.com/docs/phoenix/tracing/llm-traces) - Theo dõi (trace) quá trình chạy của ứng dụng LLM bằng instrumentation dựa trên OpenTelemetry.
- [**_Đánh giá (Evaluation)_**](https://arize.com/docs/phoenix/evaluation/llm-evals) - Tận dụng LLM để đo lường hiệu năng ứng dụng của bạn bằng các evals về phản hồi và truy xuất.
- [**_Datasets_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets) - Tạo các dataset có phiên bản gồm các ví dụ phục vụ thử nghiệm, đánh giá và fine-tuning.
- [**_Thử nghiệm (Experiments)_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets#experiments) - Theo dõi và đánh giá các thay đổi đối với prompt, LLM và truy xuất.
- [**_Playground_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts)- Tối ưu prompt, so sánh mô hình, điều chỉnh tham số và chạy lại các lệnh gọi LLM đã được trace.
- [**_Quản lý Prompt_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts/prompt-management)- Quản lý và kiểm thử các thay đổi prompt một cách có hệ thống bằng kiểm soát phiên bản, gắn thẻ và thử nghiệm.
- [**_PXI (Phoenix Intelligence)_**](https://arize.com/docs/phoenix/pxi) - Một agent kỹ thuật AI được tích hợp sẵn trong Phoenix để gỡ lỗi trace, cải tiến prompt và điều hướng sản phẩm.
- [**_Remote MCP Server_**](https://arize.com/docs/phoenix/integrations/remote-mcp) - Kết nối Claude Code, Cursor và các MCP client khác trực tiếp tới endpoint `/mcp` của phiên bản Phoenix của bạn để truy vấn trace, dataset, thử nghiệm và nhiều hơn nữa.

Phoenix không phụ thuộc vào nhà cung cấp hay ngôn ngữ, hỗ trợ sẵn các framework phổ biến ([OpenAI Agents SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai-agents-sdk), [Claude Agent SDK](https://arize.com/docs/phoenix/integrations/python/claude-agent-sdk), [LangGraph](https://arize.com/docs/phoenix/tracing/integrations-tracing/langchain), [Vercel AI SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/vercel-ai-sdk), [Mastra](https://arize.com/docs/phoenix/integrations/typescript/mastra), [CrewAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/crewai), [LlamaIndex](https://arize.com/docs/phoenix/tracing/integrations-tracing/llamaindex), [DSPy](https://arize.com/docs/phoenix/tracing/integrations-tracing/dspy)) và các nhà cung cấp LLM ([OpenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai), [Anthropic](https://arize.com/docs/phoenix/tracing/integrations-tracing/anthropic), [Google GenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/google-genai), [Google ADK](https://arize.com/docs/phoenix/integrations/llm-providers/google-gen-ai/google-adk-tracing), [AWS Bedrock](https://arize.com/docs/phoenix/tracing/integrations-tracing/bedrock), [OpenRouter](https://arize.com/docs/phoenix/integrations/python/openrouter), [LiteLLM](https://arize.com/docs/phoenix/tracing/integrations-tracing/litellm), và nhiều hơn nữa). Để biết chi tiết về auto-instrumentation, hãy xem dự án [OpenInference](https://github.com/Arize-ai/openinference).

Phoenix có thể chạy gần như ở bất cứ đâu, bao gồm máy cục bộ của bạn, môi trường triển khai container hoặc trên cloud. Xem [Môi trường](https://arize.com/docs/phoenix/environments) để được hướng dẫn chi tiết từng lựa chọn, hoặc chuyển thẳng tới [Hướng dẫn nhanh về Tracing](https://arize.com/docs/phoenix/get-started/get-started-tracing).

> [!NOTE]
> Phoenix là mã nguồn mở và tự lưu trữ (self-hosted). Nếu cần một nền tảng được quản lý, Arize cung cấp [Arize AX](https://arize.com/products/ax/) — cùng một instrumentation OpenTelemetry/OpenInference hoạt động với cả hai. Xem [bảng so sánh đầy đủ](https://arize.com/docs/phoenix/resources/frequently-asked-questions/what-is-the-difference-between-phoenix-and-arize).

## Chạy cục bộ

Cài đặt Phoenix qua `pip` hoặc `conda` để có một Phoenix hoạt động đầy đủ. Để xem tất cả các lựa chọn cài đặt và lưu trữ, hãy xem [hướng dẫn cài đặt](https://arize.com/docs/phoenix).

```shell
pip install arize-phoenix
phoenix serve
```

Hoặc chạy mà không cần cài đặt bằng [`uvx`](https://docs.astral.sh/uv/):

```shell
uvx arize-phoenix serve
```

## Trace ứng dụng của bạn

Cách nhanh nhất để gửi trace là để [coding agent](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) của bạn (Claude Code, Codex, Cursor và các công cụ khác) instrument ứng dụng. Từ thư mục dự án của bạn, hãy chạy:

```shell
npx @arizeai/phoenix-cli setup
# hoặc, khi đã cài đặt Phoenix: px setup
```

Quá trình thiết lập sẽ phát hiện framework và nhà cung cấp LLM của bạn, cài đặt đúng instrumentation [OpenInference](https://github.com/Arize-ai/openinference) và cấu hình xuất trace. Bạn muốn tự cấu hình trong code? Xem [tài liệu về tracing](https://arize.com/docs/phoenix/tracing/llm-traces).

## Triển khai

Các image container của Phoenix có sẵn trên [Docker Hub](https://hub.docker.com/r/arizephoenix/phoenix) và có thể được triển khai bằng Docker hoặc Kubernetes thông qua [Helm chart](https://github.com/Arize-ai/phoenix/tree/main/helm).

Đối với Docker Compose, Kubernetes/Helm và các lựa chọn triển khai khác, hãy xem [tài liệu về self-hosting](https://arize.com/docs/phoenix/self-hosting).

## Dành cho con người và coding agent

Phoenix được xây dựng để cả con người lẫn AI coding agent đều có thể sử dụng. Ba giao diện cho phép các agent (Claude Code, Codex, Cursor và các công cụ khác) làm việc với trace, dataset và thử nghiệm của bạn:

- **[CLI](https://arize.com/docs/phoenix/sdk-api-reference/typescript/arizeai-phoenix-cli)** — `npx @arizeai/phoenix-cli` lấy trace, dataset và thử nghiệm, đồng thời instrument ứng dụng của bạn (`setup`), để agent có thể lấy ngữ cảnh và hành động ngay từ terminal.
- **[Skills](https://docs.anthropic.com/en/docs/claude-code/skills)** — [`.agents/skills/`](../../.agents/skills/) đóng gói các quy trình dạy agent cách gỡ lỗi, đánh giá và trace với Phoenix.
- **[Remote MCP Server](https://arize.com/docs/phoenix/integrations/remote-mcp)** — kết nối bất kỳ MCP client nào tới endpoint `/mcp` của phiên bản của bạn để truy vấn Phoenix trực tiếp.

Xem [tài liệu về coding agent](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) để biết cách thiết lập và sử dụng.

| Kỹ năng                                              | Mô tả                                                                                                                |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [phoenix-cli](../../.agents/skills/phoenix-cli/)         | Gỡ lỗi ứng dụng LLM bằng Phoenix CLI — lấy trace, phân tích lỗi, xem lại thử nghiệm và truy vấn GraphQL API |
| [phoenix-evals](../../.agents/skills/phoenix-evals/)     | Xây dựng và chạy evaluator cho ứng dụng AI/LLM bằng Phoenix                                                             |
| [phoenix-tracing](../../.agents/skills/phoenix-tracing/) | Quy ước ngữ nghĩa OpenInference và instrumentation để trace ứng dụng LLM                                        |

### Telemetry

Theo mặc định, Phoenix thu thập dữ liệu phân tích web cơ bản (ví dụ: lượt xem trang, tương tác UI) để giúp chúng tôi hiểu cách Phoenix được sử dụng và cải thiện sản phẩm. **Không có dữ liệu trace, kết quả đánh giá hay bất kỳ thông tin nhạy cảm nào của bạn bị thu thập.**

Bạn có thể tắt telemetry bằng cách đặt biến môi trường: `PHOENIX_TELEMETRY_ENABLED=false`
