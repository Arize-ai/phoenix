Το Arize Phoenix είναι η πλατφόρμα παρατηρησιμότητας AI ανοιχτού κώδικα της Arize, σχεδιασμένη για πειραματισμό, αξιολόγηση και αντιμετώπιση προβλημάτων. Για διαχειριζόμενες ροές εργασίας παραγωγής, η Arize προσφέρει επίσης το [Arize AX](https://arize.com/products/ax/). Το Phoenix παρέχει:

- [**_Tracing_**](https://arize.com/docs/phoenix/tracing/llm-traces) - Παρακολουθήστε την εκτέλεση της εφαρμογής LLM σας μέσω instrumentation βασισμένου στο OpenTelemetry.
- [**_Αξιολόγηση_**](https://arize.com/docs/phoenix/evaluation/llm-evals) - Αξιοποιήστε LLM για τη μέτρηση της απόδοσης της εφαρμογής σας με evals απαντήσεων και ανάκτησης.
- [**_Σύνολα δεδομένων_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets) - Δημιουργήστε σύνολα δεδομένων παραδειγμάτων με εκδόσεις για πειραματισμό, αξιολόγηση και fine-tuning.
- [**_Πειράματα_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets#experiments) - Παρακολουθήστε και αξιολογήστε αλλαγές σε prompts, LLM και ανάκτηση.
- [**_Playground_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts)- Βελτιστοποιήστε prompts, συγκρίνετε μοντέλα, ρυθμίστε παραμέτρους και επαναλάβετε καταγεγραμμένες κλήσεις LLM.
- [**_Διαχείριση prompts_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts/prompt-management)- Διαχειριστείτε και δοκιμάστε συστηματικά αλλαγές σε prompts με έλεγχο εκδόσεων, ετικέτες και πειραματισμό.
- [**_PXI (Phoenix Intelligence)_**](https://arize.com/docs/phoenix/pxi) - Ένας agent μηχανικής AI ενσωματωμένος στο Phoenix για αποσφαλμάτωση traces, επαναληπτική βελτίωση prompts και πλοήγηση στο προϊόν.
- [**_Απομακρυσμένος διακομιστής MCP_**](https://arize.com/docs/phoenix/integrations/remote-mcp) - Συνδέστε το Claude Code, το Cursor και άλλους πελάτες MCP απευθείας στο endpoint `/mcp` της εγκατάστασης Phoenix σας για να κάνετε ερωτήματα σε traces, σύνολα δεδομένων, πειράματα και άλλα.

Το Phoenix είναι ανεξάρτητο από προμηθευτές και γλώσσες, με έτοιμη υποστήριξη για δημοφιλή frameworks ([OpenAI Agents SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai-agents-sdk), [Claude Agent SDK](https://arize.com/docs/phoenix/integrations/python/claude-agent-sdk), [LangGraph](https://arize.com/docs/phoenix/tracing/integrations-tracing/langchain), [Vercel AI SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/vercel-ai-sdk), [Mastra](https://arize.com/docs/phoenix/integrations/typescript/mastra), [CrewAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/crewai), [LlamaIndex](https://arize.com/docs/phoenix/tracing/integrations-tracing/llamaindex), [DSPy](https://arize.com/docs/phoenix/tracing/integrations-tracing/dspy)) και παρόχους LLM ([OpenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai), [Anthropic](https://arize.com/docs/phoenix/tracing/integrations-tracing/anthropic), [Google GenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/google-genai), [Google ADK](https://arize.com/docs/phoenix/integrations/llm-providers/google-gen-ai/google-adk-tracing), [AWS Bedrock](https://arize.com/docs/phoenix/tracing/integrations-tracing/bedrock), [OpenRouter](https://arize.com/docs/phoenix/integrations/python/openrouter), [LiteLLM](https://arize.com/docs/phoenix/tracing/integrations-tracing/litellm) και άλλους). Για λεπτομέρειες σχετικά με το αυτόματο instrumentation, δείτε το έργο [OpenInference](https://github.com/Arize-ai/openinference).

Το Phoenix εκτελείται σχεδόν οπουδήποτε, όπως στον τοπικό σας υπολογιστή, σε ανάπτυξη με containers ή στο cloud. Δείτε την ενότητα [Περιβάλλοντα](https://arize.com/docs/phoenix/environments) για αναλυτική περιγραφή κάθε επιλογής ή μεταβείτε κατευθείαν στον [Οδηγό γρήγορης εκκίνησης για tracing](https://arize.com/docs/phoenix/get-started/get-started-tracing).

> [!NOTE]
> Το Phoenix είναι ανοιχτού κώδικα και αυτο-φιλοξενούμενο. Για διαχειριζόμενη πλατφόρμα, η Arize προσφέρει το [Arize AX](https://arize.com/products/ax/) — το ίδιο instrumentation OpenTelemetry/OpenInference λειτουργεί και με τα δύο. Δείτε την [πλήρη σύγκριση](https://arize.com/docs/phoenix/resources/frequently-asked-questions/what-is-the-difference-between-phoenix-and-arize).

## Τοπική εκτέλεση

Εγκαταστήστε το Phoenix μέσω `pip` ή `conda` και αποκτήστε ένα πλήρως λειτουργικό Phoenix. Για όλες τις επιλογές εγκατάστασης και φιλοξενίας, δείτε τον [οδηγό εγκατάστασης](https://arize.com/docs/phoenix).

```shell
pip install arize-phoenix
phoenix serve
```

Ή εκτελέστε το χωρίς εγκατάσταση με το [`uvx`](https://docs.astral.sh/uv/):

```shell
uvx arize-phoenix serve
```

## Tracing της εφαρμογής σας

Ο ταχύτερος τρόπος για να στείλετε traces είναι να αφήσετε τον [coding agent](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) σας (Claude Code, Codex, Cursor και άλλους) να κάνει το instrumentation της εφαρμογής σας. Από τον κατάλογο του έργου σας, εκτελέστε:

```shell
npx @arizeai/phoenix-cli setup
# ή, με εγκατεστημένο το Phoenix: px setup
```

Η ρύθμιση εντοπίζει το framework και τον πάροχο LLM σας, εγκαθιστά το κατάλληλο instrumentation του [OpenInference](https://github.com/Arize-ai/openinference) και ρυθμίζει την εξαγωγή των traces. Προτιμάτε να το ρυθμίσετε μέσα στον κώδικα; Δείτε την [τεκμηρίωση για το tracing](https://arize.com/docs/phoenix/tracing/llm-traces).

## Ανάπτυξη

Για Docker Compose, Kubernetes/Helm και άλλες επιλογές ανάπτυξης, δείτε την [τεκμηρίωση αυτο-φιλοξενίας](https://arize.com/docs/phoenix/self-hosting).

## Για ανθρώπους και coding agents

Το Phoenix έχει σχεδιαστεί ώστε να χρησιμοποιείται τόσο από ανθρώπους όσο και από AI coding agents. Τρεις διεπαφές επιτρέπουν στους agents (Claude Code, Codex, Cursor και άλλους) να εργάζονται με τα traces, τα σύνολα δεδομένων και τα πειράματά σας:

- **[CLI](https://arize.com/docs/phoenix/sdk-api-reference/typescript/arizeai-phoenix-cli)** — το `npx @arizeai/phoenix-cli` ανακτά traces, σύνολα δεδομένων και πειράματα και κάνει το instrumentation της εφαρμογής σας (`setup`), ώστε ένας agent να μπορεί να αντλεί πλαίσιο και να ενεργεί με βάση αυτό από το τερματικό.
- **[Skills](https://docs.anthropic.com/en/docs/claude-code/skills)** — το [`.agents/skills/`](../../.agents/skills/) περιέχει έτοιμες ροές εργασίας που διδάσκουν στους agents πώς να κάνουν αποσφαλμάτωση, αξιολόγηση και tracing με το Phoenix.
- **[Απομακρυσμένος διακομιστής MCP](https://arize.com/docs/phoenix/integrations/remote-mcp)** — συνδέστε οποιονδήποτε πελάτη MCP στο endpoint `/mcp` της εγκατάστασής σας για να κάνετε ερωτήματα απευθείας στο Phoenix.

Δείτε την [τεκμηρίωση για coding agents](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) για οδηγίες ρύθμισης και χρήσης.

| Skill                                              | Περιγραφή                                                                                                                |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [phoenix-cli](../../.agents/skills/phoenix-cli/)         | Αποσφαλμάτωση εφαρμογών LLM με το Phoenix CLI — ανάκτηση traces, ανάλυση σφαλμάτων, επισκόπηση πειραμάτων και ερωτήματα στο GraphQL API |
| [phoenix-evals](../../.agents/skills/phoenix-evals/)     | Δημιουργία και εκτέλεση αξιολογητών για εφαρμογές AI/LLM με το Phoenix                                                             |
| [phoenix-tracing](../../.agents/skills/phoenix-tracing/) | Σημασιολογικές συμβάσεις και instrumentation του OpenInference για tracing εφαρμογών LLM                                        |

### Τηλεμετρία

Από προεπιλογή, το Phoenix συλλέγει βασικά δεδομένα ανάλυσης ιστού (π.χ. προβολές σελίδων, αλληλεπιδράσεις με το UI) για να μας βοηθήσει να κατανοήσουμε πώς χρησιμοποιείται το Phoenix και να βελτιώσουμε το προϊόν. **Δεν συλλέγονται ποτέ δεδομένα των traces σας, αποτελέσματα αξιολογήσεων ή οποιαδήποτε ευαίσθητη πληροφορία.**

Μπορείτε να απενεργοποιήσετε την τηλεμετρία ορίζοντας τη μεταβλητή περιβάλλοντος: `PHOENIX_TELEMETRY_ENABLED=false`
