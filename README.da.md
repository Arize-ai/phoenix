Arize Phoenix er Arizes open source-platform til AI-observability, designet til eksperimentering, evaluering og fejlfinding. Til administrerede produktionsworkflows tilbyder Arize også [Arize AX](https://arize.com/products/ax/). Phoenix tilbyder:

- [**_Tracing_**](https://arize.com/docs/phoenix/tracing/llm-traces) - Trace din LLM-applikations runtime med OpenTelemetry-baseret instrumentering.
- [**_Evaluering_**](https://arize.com/docs/phoenix/evaluation/llm-evals) - Brug LLM'er til at benchmarke din applikations ydeevne med evals af svar og retrieval.
- [**_Datasæt_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets) - Opret versionerede datasæt med eksempler til eksperimentering, evaluering og finjustering.
- [**_Eksperimenter_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets#experiments) - Spor og evaluer ændringer i prompts, LLM'er og retrieval.
- [**_Playground_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts)- Optimer prompts, sammenlign modeller, juster parametre og genafspil tracede LLM-kald.
- [**_Prompt-styring_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts/prompt-management)- Administrer og test prompt-ændringer systematisk med versionsstyring, tagging og eksperimentering.
- [**_PXI (Phoenix Intelligence)_**](https://arize.com/docs/phoenix/pxi) - En AI-engineering-agent indbygget i Phoenix til at debugge traces, iterere på prompts og navigere i produktet.
- [**_Remote MCP-server_**](https://arize.com/docs/phoenix/integrations/remote-mcp) - Forbind Claude Code, Cursor og andre MCP-klienter direkte til din Phoenix-instans' `/mcp`-endpoint for at forespørge på traces, datasæt, eksperimenter og meget mere.

Phoenix er leverandør- og sproguafhængig med indbygget understøttelse af populære frameworks ([OpenAI Agents SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai-agents-sdk), [Claude Agent SDK](https://arize.com/docs/phoenix/integrations/python/claude-agent-sdk), [LangGraph](https://arize.com/docs/phoenix/tracing/integrations-tracing/langchain), [Vercel AI SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/vercel-ai-sdk), [Mastra](https://arize.com/docs/phoenix/integrations/typescript/mastra), [CrewAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/crewai), [LlamaIndex](https://arize.com/docs/phoenix/tracing/integrations-tracing/llamaindex), [DSPy](https://arize.com/docs/phoenix/tracing/integrations-tracing/dspy)) og LLM-udbydere ([OpenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai), [Anthropic](https://arize.com/docs/phoenix/tracing/integrations-tracing/anthropic), [Google GenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/google-genai), [Google ADK](https://arize.com/docs/phoenix/integrations/llm-providers/google-gen-ai/google-adk-tracing), [AWS Bedrock](https://arize.com/docs/phoenix/tracing/integrations-tracing/bedrock), [OpenRouter](https://arize.com/docs/phoenix/integrations/python/openrouter), [LiteLLM](https://arize.com/docs/phoenix/tracing/integrations-tracing/litellm) og flere). Se [OpenInference](https://github.com/Arize-ai/openinference)-projektet for detaljer om automatisk instrumentering.

Phoenix kører stort set overalt, herunder på din lokale maskine, i en containeriseret udrulning eller i skyen. Se [Miljøer](https://arize.com/docs/phoenix/environments) for en gennemgang af hver mulighed, eller gå direkte til [Tracing Quickstart](https://arize.com/docs/phoenix/get-started/get-started-tracing).

> [!NOTE]
> Phoenix er open source og selvhostet. Som administreret platform tilbyder Arize [Arize AX](https://arize.com/products/ax/) — den samme OpenTelemetry/OpenInference-instrumentering fungerer med begge. Se den [fulde sammenligning](https://arize.com/docs/phoenix/resources/frequently-asked-questions/what-is-the-difference-between-phoenix-and-arize).

## Kør lokalt

Installer Phoenix via `pip` eller `conda`, og få et fuldt funktionelt Phoenix. Se [installationsguiden](https://arize.com/docs/phoenix) for alle installations- og hostingmuligheder.

```shell
pip install arize-phoenix
phoenix serve
```

Eller kør det uden installation med [`uvx`](https://docs.astral.sh/uv/):

```shell
uvx arize-phoenix serve
```

## Trace din applikation

Den hurtigste måde at sende traces på er at lade din [kodeagent](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) (Claude Code, Codex, Cursor og andre) instrumentere din app. Kør følgende fra din projektmappe:

```shell
npx @arizeai/phoenix-cli setup
# eller, med Phoenix installeret: px setup
```

Opsætningen registrerer dit framework og din LLM-udbyder, installerer den rette [OpenInference](https://github.com/Arize-ai/openinference)-instrumentering og sætter trace-eksport op. Foretrækker du at sætte det op i kode? Se [tracing-dokumentationen](https://arize.com/docs/phoenix/tracing/llm-traces).

## Tracing-integrationer

## Til mennesker og kodeagenter

Phoenix er bygget til at blive styret af både mennesker og AI-kodeagenter. Tre grænseflader lader agenter (Claude Code, Codex, Cursor og andre) arbejde med dine traces, datasæt og eksperimenter:

- **[CLI](https://arize.com/docs/phoenix/sdk-api-reference/typescript/arizeai-phoenix-cli)** — `npx @arizeai/phoenix-cli` henter traces, datasæt og eksperimenter og instrumenterer din app (`setup`), så en agent kan hente kontekst og handle på den fra terminalen.
- **[Skills](https://docs.anthropic.com/en/docs/claude-code/skills)** — [`.agents/skills/`](.agents/skills/) pakker workflows, der lærer agenter at debugge, evaluere og trace med Phoenix.
- **[Remote MCP-server](https://arize.com/docs/phoenix/integrations/remote-mcp)** — forbind en hvilken som helst MCP-klient til din instans' `/mcp`-endpoint for at forespørge direkte på Phoenix.

Se [dokumentationen om kodeagenter](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) for opsætning og brug.

| Skill                                              | Beskrivelse                                                                                                                |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [phoenix-cli](.agents/skills/phoenix-cli/)         | Debug LLM-applikationer med Phoenix CLI — hent traces, analysér fejl, gennemgå eksperimenter og forespørg på GraphQL-API'et |
| [phoenix-evals](.agents/skills/phoenix-evals/)     | Byg og kør evaluatorer til AI/LLM-applikationer med Phoenix                                                             |
| [phoenix-tracing](.agents/skills/phoenix-tracing/) | Semantiske konventioner og instrumentering fra OpenInference til tracing af LLM-applikationer                                        |

### Telemetri

Som standard indsamler Phoenix grundlæggende webanalyse (f.eks. sidevisninger og UI-interaktioner) for at hjælpe os med at forstå, hvordan Phoenix bruges, og forbedre produktet. **Ingen af dine trace-data, evalueringsresultater eller andre følsomme oplysninger indsamles nogensinde.**

Du kan fravælge telemetri ved at sætte miljøvariablen: `PHOENIX_TELEMETRY_ENABLED=false`
