# Deployment tutorials (deprecated)

The AWS CloudFormation deployment tutorial that used to live here has moved into
the documentation. The CloudFormation templates (`phoenix-network.yml`,
`phoenix-auth.yml`, `app.yml`) and the IAM policy document (`permissions.json`)
are now inlined in the guide itself, so there is nothing left to clone from this
directory:

**[Self-hosting → Deployment options → AWS with CloudFormation](https://arize.com/docs/phoenix/self-hosting/deployment-options/aws-with-cloudformation)**

For other deployment targets, see the
[self-hosting guide](https://arize.com/docs/phoenix/self-hosting), which covers
Docker, Kubernetes, Helm, Railway, Render, Google Cloud Run, and Azure.

This directory is kept only so existing links do not dead-end, and will be
removed in a future release.
