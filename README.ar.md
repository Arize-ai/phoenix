Arize Phoenix هي منصة Arize مفتوحة المصدر لقابلية مراقبة الذكاء الاصطناعي (AI observability)، وهي مصممة للتجريب والتقييم واستكشاف الأخطاء وإصلاحها. ولسير العمل المُدار في بيئات الإنتاج، تقدم Arize أيضًا [Arize AX](https://arize.com/products/ax/). توفر Phoenix ما يلي:

- [**_التتبع (Tracing)_**](https://arize.com/docs/phoenix/tracing/llm-traces) - تتبّع وقت تشغيل تطبيق LLM الخاص بك باستخدام أدوات قياس (instrumentation) مبنية على OpenTelemetry.
- [**_التقييم (Evaluation)_**](https://arize.com/docs/phoenix/evaluation/llm-evals) - استفد من نماذج LLM لقياس أداء تطبيقك باستخدام evals للاستجابات والاسترجاع.
- [**_مجموعات البيانات (Datasets)_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets) - أنشئ مجموعات بيانات ذات إصدارات من الأمثلة للتجريب والتقييم والضبط الدقيق (fine-tuning).
- [**_التجارب (Experiments)_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets#experiments) - تتبّع وقيّم التغييرات على الـ prompts ونماذج LLM والاسترجاع.
- [**_Playground_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts)- حسّن الـ prompts، وقارن بين النماذج، واضبط المعاملات، وأعد تشغيل استدعاءات LLM المتتبَّعة.
- [**_إدارة الـ Prompts_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts/prompt-management)- أدِر واختبر تغييرات الـ prompts بشكل منهجي باستخدام التحكم في الإصدارات والوسوم والتجريب.
- [**_PXI (Phoenix Intelligence)_**](https://arize.com/docs/phoenix/pxi) - وكيل هندسة ذكاء اصطناعي مدمج في Phoenix لتصحيح أخطاء الـ traces، والتحسين التكراري للـ prompts، والتنقل في المنتج.
- [**_خادم MCP البعيد_**](https://arize.com/docs/phoenix/integrations/remote-mcp) - اربط Claude Code وCursor وعملاء MCP الآخرين مباشرةً بنقطة النهاية `/mcp` في نسخة Phoenix الخاصة بك للاستعلام عن الـ traces ومجموعات البيانات والتجارب وغير ذلك.

Phoenix مستقلة عن المزوّد واللغة، مع دعم جاهز لأطر العمل الشائعة ([OpenAI Agents SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai-agents-sdk)، [Claude Agent SDK](https://arize.com/docs/phoenix/integrations/python/claude-agent-sdk)، [LangGraph](https://arize.com/docs/phoenix/tracing/integrations-tracing/langchain)، [Vercel AI SDK](https://arize.com/docs/phoenix/tracing/integrations-tracing/vercel-ai-sdk)، [Mastra](https://arize.com/docs/phoenix/integrations/typescript/mastra)، [CrewAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/crewai)، [LlamaIndex](https://arize.com/docs/phoenix/tracing/integrations-tracing/llamaindex)، [DSPy](https://arize.com/docs/phoenix/tracing/integrations-tracing/dspy)) ومزوّدي LLM ([OpenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/openai)، [Anthropic](https://arize.com/docs/phoenix/tracing/integrations-tracing/anthropic)، [Google GenAI](https://arize.com/docs/phoenix/tracing/integrations-tracing/google-genai)، [Google ADK](https://arize.com/docs/phoenix/integrations/llm-providers/google-gen-ai/google-adk-tracing)، [AWS Bedrock](https://arize.com/docs/phoenix/tracing/integrations-tracing/bedrock)، [OpenRouter](https://arize.com/docs/phoenix/integrations/python/openrouter)، [LiteLLM](https://arize.com/docs/phoenix/tracing/integrations-tracing/litellm)، وغيرها). لمزيد من التفاصيل حول القياس التلقائي (auto-instrumentation)، اطّلع على مشروع [OpenInference](https://github.com/Arize-ai/openinference).

تعمل Phoenix في أي مكان تقريبًا، بما في ذلك جهازك المحلي، أو في نشر عبر الحاويات، أو في السحابة. راجع [البيئات](https://arize.com/docs/phoenix/environments) للاطلاع على شرح لكل خيار، أو انتقل مباشرةً إلى [دليل البدء السريع للتتبع](https://arize.com/docs/phoenix/get-started/get-started-tracing).

> [!NOTE]
> Phoenix مفتوحة المصدر وذاتية الاستضافة. وللحصول على منصة مُدارة، تقدم Arize منصة [Arize AX](https://arize.com/products/ax/) — وتعمل أدوات القياس نفسها من OpenTelemetry/OpenInference مع كلتيهما. راجع [المقارنة الكاملة](https://arize.com/docs/phoenix/resources/frequently-asked-questions/what-is-the-difference-between-phoenix-and-arize).

## التشغيل محليًا

ثبّت Phoenix عبر `pip` أو `conda` واحصل على Phoenix بكامل وظائفها. لجميع خيارات التثبيت والاستضافة، راجع [دليل التثبيت](https://arize.com/docs/phoenix).

```shell
pip install arize-phoenix
phoenix serve
```

أو شغّلها دون تثبيت باستخدام [`uvx`](https://docs.astral.sh/uv/):

```shell
uvx arize-phoenix serve
```

## تتبّع تطبيقك

أسرع طريقة لإرسال الـ traces هي أن تترك [وكيل البرمجة](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) الخاص بك (Claude Code وCodex وCursor وغيرها) يضيف أدوات القياس إلى تطبيقك. من مجلد مشروعك، شغّل:

```shell
npx @arizeai/phoenix-cli setup
# أو، إذا كانت Phoenix مثبّتة: px setup
```

يكتشف الإعداد إطار العمل ومزوّد LLM الخاصين بك، ويثبّت أدوات القياس المناسبة من [OpenInference](https://github.com/Arize-ai/openinference)، ويهيّئ تصدير الـ traces. هل تفضّل إعداد ذلك في الكود؟ راجع [توثيق التتبع](https://arize.com/docs/phoenix/tracing/llm-traces).

## للبشر ولوكلاء البرمجة

صُممت Phoenix ليستخدمها البشر ووكلاء البرمجة بالذكاء الاصطناعي على حد سواء. تتيح ثلاث واجهات للوكلاء (Claude Code وCodex وCursor وغيرها) العمل مع الـ traces ومجموعات البيانات والتجارب الخاصة بك:

- **[CLI](https://arize.com/docs/phoenix/sdk-api-reference/typescript/arizeai-phoenix-cli)** — يجلب `npx @arizeai/phoenix-cli` الـ traces ومجموعات البيانات والتجارب ويضيف أدوات القياس إلى تطبيقك (`setup`)، بحيث يمكن للوكيل جلب السياق والتصرف بناءً عليه من الطرفية.
- **[Skills](https://docs.anthropic.com/en/docs/claude-code/skills)** — تحزم [`.agents/skills/`](.agents/skills/) سير عمل يعلّم الوكلاء كيفية تصحيح الأخطاء والتقييم والتتبع باستخدام Phoenix.
- **[خادم MCP البعيد](https://arize.com/docs/phoenix/integrations/remote-mcp)** — اربط أي عميل MCP بنقطة النهاية `/mcp` في نسختك للاستعلام من Phoenix مباشرةً.

راجع [توثيق وكلاء البرمجة](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) للإعداد والاستخدام.

| المهارة (Skill) | الوصف |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [phoenix-cli](.agents/skills/phoenix-cli/) | تصحيح أخطاء تطبيقات LLM باستخدام Phoenix CLI — جلب الـ traces وتحليل الأخطاء ومراجعة التجارب والاستعلام عبر GraphQL API |
| [phoenix-evals](.agents/skills/phoenix-evals/) | بناء وتشغيل المقيّمات لتطبيقات AI/LLM باستخدام Phoenix |
| [phoenix-tracing](.agents/skills/phoenix-tracing/) | الاصطلاحات الدلالية وأدوات القياس من OpenInference لتتبّع تطبيقات LLM |

### القياس عن بُعد (Telemetry)

بشكل افتراضي، تجمع Phoenix تحليلات ويب أساسية (مثل مشاهدات الصفحات والتفاعلات مع الواجهة) لمساعدتنا على فهم كيفية استخدام Phoenix وتحسين المنتج. **لا يتم أبدًا جمع أي من بيانات الـ traces أو نتائج التقييم أو أي معلومات حساسة.**

يمكنك إلغاء الاشتراك في القياس عن بُعد بتعيين متغير البيئة: `PHOENIX_TELEMETRY_ENABLED=false`
