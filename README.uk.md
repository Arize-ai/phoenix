Arize Phoenix — це open-source платформа спостережуваності (observability) для ШІ від Arize, призначена для експериментів, оцінювання та усунення несправностей. Для керованих production-процесів Arize також пропонує [Arize AX](https://arize.com/products/ax/). Phoenix надає:

- [**_Трасування_**](https://arize.com/docs/phoenix/tracing/llm-traces) — трасуйте виконання Вашого LLM-застосунку за допомогою інструментування на основі OpenTelemetry.
- [**_Оцінювання_**](https://arize.com/docs/phoenix/evaluation/llm-evals) — використовуйте LLM для бенчмаркінгу продуктивності застосунку за допомогою оцінок (evals) відповідей і пошуку (retrieval).
- [**_Датасети_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets) — створюйте версіоновані датасети прикладів для експериментів, оцінювання та донавчання (fine-tuning).
- [**_Експерименти_**](https://arize.com/docs/phoenix/datasets-and-experiments/overview-datasets#experiments) — відстежуйте та оцінюйте зміни промптів, LLM і пошуку (retrieval).
- [**_Playground_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts)— оптимізуйте промпти, порівнюйте моделі, налаштовуйте параметри та відтворюйте трасовані виклики LLM.
- [**_Керування промптами_**](https://arize.com/docs/phoenix/prompt-engineering/overview-prompts/prompt-management)— систематично керуйте змінами промптів і тестуйте їх за допомогою контролю версій, тегів та експериментів.
- [**_PXI (Phoenix Intelligence)_**](https://arize.com/docs/phoenix/pxi) — вбудований у Phoenix ШІ-агент для інженерних завдань: налагодження трейсів, ітерації над промптами та навігація продуктом.
- [**_Віддалений MCP-сервер_**](https://arize.com/docs/phoenix/integrations/remote-mcp) — підключайте Claude Code, Cursor та інші MCP-клієнти безпосередньо до ендпоінта `/mcp` Вашого екземпляра Phoenix, щоб запитувати трейси, датасети, експерименти та багато іншого.

Докладніше про автоматичне інструментування див. проєкт [OpenInference](https://github.com/Arize-ai/openinference).

Phoenix працює практично будь-де: на Вашому локальному комп'ютері, у контейнерному розгортанні або в хмарі. Опис кожного варіанта див. у розділі [Середовища](https://arize.com/docs/phoenix/environments) або одразу переходьте до [короткого посібника з трасування](https://arize.com/docs/phoenix/get-started/get-started-tracing).

> [!NOTE]
> Phoenix — це open-source рішення із самостійним розміщенням. Як керовану платформу Arize пропонує [Arize AX](https://arize.com/products/ax/) — одне й те саме інструментування OpenTelemetry/OpenInference працює з обома. Див. [повне порівняння](https://arize.com/docs/phoenix/resources/frequently-asked-questions/what-is-the-difference-between-phoenix-and-arize).

## Локальний запуск

Установіть Phoenix через `pip` або `conda` і отримайте повнофункціональний Phoenix. Усі варіанти встановлення та розміщення описано в [посібнику з установлення](https://arize.com/docs/phoenix).

```shell
pip install arize-phoenix
phoenix serve
```

Або запустіть його без установлення за допомогою [`uvx`](https://docs.astral.sh/uv/):

```shell
uvx arize-phoenix serve
```

## Трасування застосунку

Найшвидший спосіб надсилати трейси — доручити інструментування застосунку Вашому [ШІ-агенту для програмування](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents) (Claude Code, Codex, Cursor та іншим). Виконайте в каталозі проєкту:

```shell
npx @arizeai/phoenix-cli setup
# або, якщо Phoenix установлено: px setup
```

Setup визначає Ваш фреймворк і LLM-провайдера, встановлює відповідне інструментування [OpenInference](https://github.com/Arize-ai/openinference) і налаштовує експорт трейсів. Бажаєте налаштувати все в коді? Див. [документацію з трасування](https://arize.com/docs/phoenix/tracing/llm-traces).

## Для людей і ШІ-агентів для програмування

Phoenix створено для роботи як з людьми, так і з ШІ-агентами для програмування. Три інтерфейси дають змогу агентам (Claude Code, Codex, Cursor та іншим) працювати з Вашими трейсами, датасетами та експериментами:

- **[CLI](https://arize.com/docs/phoenix/sdk-api-reference/typescript/arizeai-phoenix-cli)** — `npx @arizeai/phoenix-cli` отримує трейси, датасети й експерименти та інструментує Ваш застосунок (`setup`), тож агент може отримувати контекст і діяти на його основі просто з термінала.
- **[Навички (Skills)](https://docs.anthropic.com/en/docs/claude-code/skills)** — [`.agents/skills/`](.agents/skills/) пакує робочі процеси, які навчають агентів налагоджувати, оцінювати та трасувати за допомогою Phoenix.
- **[Віддалений MCP-сервер](https://arize.com/docs/phoenix/integrations/remote-mcp)** — підключіть будь-який MCP-клієнт до ендпоінта `/mcp` Вашого екземпляра, щоб безпосередньо виконувати запити до Phoenix.

Налаштування та використання описано в [документації щодо ШІ-агентів для програмування](https://arize.com/docs/phoenix/integrations/developer-tools/coding-agents).

| Навичка                                              | Опис                                                                                                                |
| -------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| [phoenix-cli](.agents/skills/phoenix-cli/)         | Налагодження LLM-застосунків за допомогою Phoenix CLI — отримання трейсів, аналіз помилок, перегляд експериментів і запити до GraphQL API |
| [phoenix-evals](.agents/skills/phoenix-evals/)     | Створення та запуск оцінювачів для AI/LLM-застосунків за допомогою Phoenix                                                             |
| [phoenix-tracing](.agents/skills/phoenix-tracing/) | Семантичні конвенції OpenInference та інструментування для трасування LLM-застосунків                                        |

### Телеметрія

За замовчуванням Phoenix збирає базову веб-аналітику (наприклад, перегляди сторінок, взаємодії з інтерфейсом), щоб допомогти нам зрозуміти, як використовується Phoenix, і покращити продукт. **Ваші дані трейсів, результати оцінювання та будь-яка конфіденційна інформація ніколи не збираються.**

Ви можете відмовитися від телеметрії, встановивши змінну середовища: `PHOENIX_TELEMETRY_ENABLED=false`
